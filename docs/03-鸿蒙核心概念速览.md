# 03 鸿蒙核心概念速览

本文对齐当前 Stage 工程术语。具体 SDK 和工具版本见 [平台基线](02-平台基线.md)。

## 1. 应用包与模块

| 类型 | 职责 | 本仓库用途 |
|---|---|---|
| APP | 应用发布集合 | 汇集应用安装与分发所需模块 |
| HAP | 应用安装与运行模块 | entry，含页面、UIAbility 与应用服务 |
| HAR | 静态共享源码/资源模块 | Agent 八模块，本地源码依赖 |
| HSP | 动态共享包 | 当前未使用 |

HAR 不声明 UIAbility / AbilityStage，也不作为独立应用上架。同一设备类型只保留一个 entry 类型 HAP。独立 Windows/.NET 服务不属于上述手机应用包。

## 2. Stage 启动与生命周期

`EntryAbility` 是 UIAbility 入口，创建 WindowStage 后加载 `pages/Index`，页面必须同时在资源清单注册。Ability、页面、模型会话和任务拥有各自生命周期，页面切换不自动代表整个宿主关闭。

退后台停止活动外发和持有资源；回前台不自动重发旧任务。取消本机等待、停止远端处理和撤销已完成系统写入分别报告。

## 3. 配置位置

| 文件 | 用途 |
|---|---|
| AppScope/app.json5 | bundleName、版本、应用图标与名称 |
| entry/src/main/module.json5 | HAP、设备类型、Ability、权限与页面配置 |
| entry/src/main/resources/base/profile/main_pages.json | 页面清单 |
| build-profile.json5 | 产品、SDK、模块与无签名模板 |
| oh-package.json5 | OHPM 依赖 |
| hvigor/hvigor-config.json5 | Hvigor 基线 |

当前 entry 支持 phone / tablet，申请网络、麦克风和日历读写权限，按功能检查及授权。页面使用应用服务，核心不依赖页面或具体平台适配。

## 4. 构建、签名与设备

`devecocli build` 完成编译打包，安装需有效签名；构建成功后才运行。`scripts/dev-run.sh` / Windows 包装入口串联目标选择、签名缓存、构建和安装启动，macOS 使用独立脚本。

构建产物、签名材料和设备数据分别管理。源码兼容、构建通过、模拟器机制与真机验收各有独立证据，详见 [脚本说明](../scripts/README.md) 与 [协作规则](01-协作与工程约定.md)。
