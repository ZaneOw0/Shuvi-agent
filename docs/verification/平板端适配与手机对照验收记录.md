## 1. 本轮改动

| 文件 | 改动 |
|---|---|
| `entry/src/main/ets/model/ResponsiveLayoutPolicy.ets` | 新增纯布局策略：`embedded` 840vp；`sideWidth` 240–280vp；`contentLimit` 640/720/840/960vp；`compactActions` 480vp。只依赖尺寸，不读设备类型、Key 或持久化 |
| `entry/src/main/ets/pages/Index.ets` | 外层窗口宽度 `onAreaChange` → `resizeWindow`；`SideBarContainer` 在 Overlay/Embed 间切换；遮罩/无障碍/enabled 只在窄屏抽屉生效；侧栏宽度与内容限宽接入策略；知识库授权标签按内容宽度缩短；补 `drawer-tab-*`、`responsive-shell` 稳定 id；`PdfJsSurface` 从侧栏分支内提升到导航与内容之上 |
| `entry/src/main/module.json5` | `EntryAbility` 增加 `orientation: auto_rotation`，横竖屏由系统旋转驱动真实重排 |
| `entry/src/test/run-responsive-layout-tests.cjs` | 8 条纯逻辑/真实回调用例（断点、非法尺寸、侧栏与内容、紧凑标签、回调不丢状态、内容宽度不回灌、悬浮吸边） |
| `scripts/tests/tablet-layout-device-smoke.cjs` | 平板设备导航 smoke：有界轮询等待替代固定 sleep，超时输出可见控件 id；只点击导航，不发送、不检索、不写日历 |
| `scripts/l0-host-summary.cjs` | 增加 `--layout`、`--calendar` 汇总入口 |

未改动 Agent、知识库核心、RAG 授权、模型预算、数据库布局与工具写入规则；未新增依赖、权限或服务。

## 4. 未完成与阻塞

1. **日程写入**：平板只到确认卡与系统权限申请，用户侧停止后续操作，未取得「创建成功 + 系统读回 + 提醒送达」；手机未做写入。
2. **手机知识库**：138MB 既有库首次打开 182–222 秒、CPU 满载；未清理数据、未定位具体阶段，需单独排查（属既有数据/性能问题，非本轮布局改动）。
3. **手机端模型与检索**：不跨端搬运 Key，手机未配置 Provider，L1/L2、搜索、DOCX/图片导入只在平板侧验证。
4. **异常与失败路径**：空资料、坏文件、取消选择、断网、权限拒绝、模型失败、后台回收本轮未取证。
5. **较大字体 / 系统字体缩放 / 系统分屏**：未实测；窄窗使用自由窗口，不等同分屏。
6. **真机**：模拟器结果不能替代 ARM 平板/手机真机。

## 5. 复现命令

```text
node scripts/l0-host-summary.cjs --layout
node scripts/l0-host-summary.cjs --full-host
devecocli build --modules entry --product default
DEVECO_SDK_HOME=<sdk> TABLET_TEST_DEVICE=127.0.0.1:5555 node scripts/tests/tablet-layout-device-smoke.cjs
```

设备侧前置：应用已安装并运行、无未发送草稿、无进行中回答/录音/PDF 预览；smoke 只做导航与截图，失败会打印可见控件 id。同一时间只运行一个模拟器实例。
