## 1. 范围

验证后端 `RuntimeVisionService.session` 的真实设备行为：

- 图片读取、校验、重编码（JPEG/PNG/WebP、EXIF 方向、尺寸/字节边界）；
- 显式同意、会话 Key、停止/后台清理；
- 真实 DeepSeek 视觉请求与严格 JSON/引用；
- 取消、迟到结果、失败/重试、请求上限；
- 日志不含图片内容、问题、文件名、路径或 Key。

不覆盖：前端布局/无障碍、真机 OpenHarmony、供应商账单核验本身。

## 2. 安全前置

- 使用**合成测试图片**，不含个人照片、证件、地址、聊天截图或真实文档。
- Key 只在设备调用入口输入；不写入脚本、命令、日志、截图或本仓库。
- 不读取或清理用户已有日历、知识库、图片或应用数据。
- 使用本机临时签名安装 debug 包；证书材料不得入库。
- 设备日志只保留脱敏摘要；不要把原始提示词、图片 base64、文件名或 Key 复制到公共记录。
- 若调用入口尚未存在，只能做“安装/启动/停止”烟测，不能把 attach/send 标为通过。

## 4. 执行方式（需授权后）

1. 构建并安装 debug 包（本机临时签名）：
   - 只在用户明确授权安装时执行；
   - 记录包名、版本、安装时间、设备 serial；不记录签名材料。
2. 打开调用入口，按 V-01～V-16 逐项操作；每项记录状态、是否产生模型请求、是否计费未知。
3. 采集设备日志：
   - 使用 `scripts/capture-test-log.sh` 落盘；必要时显式设置 `DEVECOCLI_BIN`；
   - 如果公共过滤拒绝输出，改用 `hdc hilog` 全缓冲脱敏摘要，只记录计数和分类；
   - 不把原始日志直接贴入文档。
4. 截图只保留合成测试图片和状态，不包含 Key 输入框内容。
5. 记录设备侧图片/请求上限异常，不改代码“跑通”。

## 5. 通过标准

- V-01～V-18 全部通过，或每个失败项都有可复现步骤、日志路径和明确未通过结论。
- 无 Key/图片/文件名/问题内容泄漏到日志、截图或文档。
- 真实模型请求的 token/费用只记“供应商报告/未核账”，不写成实际扣费。
- 设备/模拟器与真机分别记录；模拟器通过不替代 OpenHarmony 真机。

### 6.1 纯测试入口（2026-10-26）

新增 `entry/src/ohosTest` 设备测试入口，不进入产品页面；测试包为 `entry_test`，使用 Hypium/`OpenHarmonyTestRunner`，只调用后端 `VisionImagePreparer` 与 `RuntimeVisionSession`。

`VisionDeviceTest` 设备结果 **11/11 通过**：

1. 合成 1×1 PNG、64×64 JPEG、64×64 WebP 经真实 `VisionImagePreparer` 读取/校验/重编码，mime、尺寸与 SHA-256 有效；
2. 透明 PNG 重编码后 alpha 保留；
3. 带 EXIF Orientation=6 的 JPEG 被旋转为预期 4×8 方向，顶部红色、底部蓝色；
4. 2048×2048 纯色 PNG 被接受，最长边保持 2048；2048×2048 噪声 PNG 因重编码超过 8MB 被拒绝为 `IMAGE_SANITIZED_BUDGET`；
5. 伪造 PNG 被拒绝为 `IMAGE_HEADER_INVALID`；
6. 会话暴露 `maxRequests=10`、`requestCount=0`、`pricingState=unverified`，停止后 `imageReady=false`；
7. 假运行时下取消保留图片并结束忙碌、停止清空图片且不能再次发送、第 11 次请求不提交。

测试 HAP 构建 **82 任务**（69 执行、13 最新）通过，安装为 `entry_test`；`aa test -b com.example.shuvi -m entry_test -s unittest OpenHarmonyTestRunner -s class VisionDeviceTest -s timeout 240000` 返回 0。未发送模型请求，未使用 Key。

这覆盖了 V-01/V-02/V-03 的图片准备、V-04 的 Orientation=6、V-05/V-06 的部分后端边界、V-15/V-16 的假运行时部分；**不覆盖**前端同意、真实模型/账单、其他 EXIF 方向、>20MB/20MP、完整 V-01～V-18。证据：`.cache/test-logs/2026-10-26-vision-route2-device-test-build-2-42101a3/`、`.cache/test-logs/2026-10-26-vision-route2-device-test-install-2-42101a3/`、`.cache/test-logs/2026-10-26-vision-route2-device-test-3-42101a3/`。
