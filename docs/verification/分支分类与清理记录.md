## 4. 命令、结果与记录归属

GitHub 连接器用于核对 PR；Git 用于读取实际远端、祖先和引用状态及删除操作。远端目标和删除前 SHA 已在本机 `.cache/branch-cleanup-before.json` 留存。

```bash
git ls-remote --heads origin
git branch -vv
git worktree list --porcelain
git merge-base --is-ancestor <sha> main
git push origin --delete <明确列出的临时分支>
git branch -d <明确列出的本地临时分支>
```

操作结果：远端 15 个、本地 3 个临时分支删除成功。清理后实际远端为 6 个、本地为 7 个；逐项核对保留分支 SHA 与删除前一致，当前仍为 fix/patch。删除后快照位于 `.cache/branch-cleanup-after.json`。

分支引用删除立即作用于本机或 GitHub，不会自动成为 fix/patch 的提交。本文件放在当前 fix/patch 工作区并纳入 Git；提交后才随该分支历史保存。本轮不自动提交、推送记录、改动 main、合并或变基；未修改应用代码、锁文件、标签及 worktree 内容。
