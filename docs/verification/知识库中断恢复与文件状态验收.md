日期：2026-10-22。基线：`dev/rag` / `9ab89b4`，本轮修改未提交、未推送。状态：已实现待验收；受控回归、构建安装与本轮模拟器界面机制验收通过，真机及真实 MinerU 断网验收未执行。本文独立记录本轮用户故事、行为变更、断点矩阵及证据，不把受控网络替身当作真实云端故障验收。

## 用户流程

用户导入文件后，依次经历原件保存/预检、MinerU 申请与上传、同任务云解析、结果包接收、本机统一内容发布、图片描述/tag、正文与图片代理向量读回发布、检索与来源打开。任一阶段中断保留上一已确认结果；恢复必须基于同一文件、版本、任务及当前授权，不为了继续而清空账本、换新批次或把未知结果冒充失败/成功。

资料列表与详情汇总当前文档代和 epoch 的作业；未完成显示「部分入库」，正文/OCR 已可本机检索与语义尚未就绪分开表达。详情内可查看该文件的处理阶段、进度、失败说明，对 Unknown/Failed/Paused 作业按 ID 单独重新入队，已成功且身份吻合的向量核验复用。只点击任务“重试”先展示范围与可能费用，确认才重新入队。

## 页面事项

- 详情默认显示最多五项当前文件作业，正文向量任务优先；「查看全部处理任务」可展开全部，没有丢弃尾部任务。全局图片理解设置中的混合作业列表改为每组十项可翻页。
- 取消原来只重开队列、无法恢复 Unknown 的「重试自动处理」按钮；明确的单任务重试不重置其他作业。
- 原件存在但上传/解析未完成时显示中断状态，可在文件详情「核对并恢复原云任务」；确认同账号与可能补传/结果重取范围后恢复，不重新申请批次。
- 本机入库失败保留「保存到知识库」「重试保存内容」和从已接收结果恢复的入口；不会以重跑云解析代替本机恢复。
- MinerU 页顶部「本机副本」直达独立管理区，支持按文件名筛选。删除本机解析副本先等待实际结果，再在删除按钮附近显示「已删除」或「未删除及原因」。被知识库引用保护拒绝时保留记录及确认入口，提示先在「我的资料」处理相应引用，不强删受管来源。
- 切换文件先清空旧正文/图片并显示当前文件加载状态。渲染 key 包含文档、代、块/行身份；晚到的旧读取不会覆盖新文件，失败可重试打开内容。

## 业务与恢复边界

本轮按用户明确要求扩大**产品手动恢复**范围，原有固定测试许可不扩展：

- 普通图片、DOCX 的首次申请仍最多一次；不重建 batch。仅明确点击恢复、查询原批次确认为 waiting-file、原件 hash/version、账号凭据 revision 与原租约均吻合时，允许同对象最多补传一次（总 PUT 最多两次）。旧 U01–U11 固定图片测试许可维持原一次 PUT 限制。
- 普通图片、DOCX 失败结果包允许用户手动恢复后最多重取两次（总 ZIP 接收尝试最多三次）。每次仍查询同任务并验证租约、真实流结束、长度/hash/签名和关联，成功后只读缓存。不是字节级续传，不自动循环下载。
- PUT/ZIP 累计计数只递增，仓储重开保留，不通过重置计数伪装首次请求；没有新增数据库表、权限、依赖或云服务。
- 暂停/重开不撤销已形成任务且仍匹配的 DOCX 文件授权；确认保存中尚未形成任务的许可仍撤销。关闭功能、换凭据/版本等原有撤销与准入守卫保留。恢复仍要求用户确认同账号。
- 不明申请身份、过期/丢失租约、变化的文件/凭据、明确云端失败等不能假恢复。保留原件/占用并说明阻断原因；不自动重新申请或绕过已有服务/费用条件。
- 文件级重试只把被选作业重新排队；队列本身已暂停或设置关闭时仍需恢复对应设置，不能借单任务重试隐式开启整库外发。

### 未覆盖与不可假恢复的边界

- 本轮没有新增真实 MinerU/视觉/嵌入调用，没有对真实账号做飞行模式/断网/进程强杀/磁盘满/断电故障注入。真实 SDK 传输中断仍需单独的自制样本和费用资格验收；本报告不能称所有真实云异常已通过。
- 任意原件永久丢失、申请 batch 身份未返回、预签名地址过期、明确远端服务失败、用户撤销/更换账号，不保证可继续同一任务。现实现会明确保留并报错，不另建任务或篡改请求预算。收到有效错误后仍可能需用户重新选择文件或处理服务账号。
- 第四次 ZIP 接收及第二次补传被预算阻止时保留可理解错误；没有为“跑通”清空计数。回退旧应用可能无法读取已达到新恢复计数的记录，应保留此版本，不重置数据库。
- 当前「部分入库」表示本机基础内容可用、至少一个当前处理作业尚未完成，不代表已有同比例文本可语义检索；完整向量资格仍须全部输入核验成功。
- 文本首屏模拟器验收使用自制 A/B；用户提到的两份原文未另行外发或删除，也不以阅读其内容作为测试必要条件。


### 断点矩阵（受控故障注入）

| 环节 | 注入/触发 | 核验结果与恢复约束 |
|---|---|---|
| 原件存在与预检 | 原件缺失 | 申请请求 0；保留原件登记及可理解错误，不冒可上传 |
| 申请 | 请求发出后身份未知 | Uncertain，原件/hash/version 与任务保留；继续核对不产生第二次 POST |
| 上传 | 上传已经开始、仅供给部分字节后断网 | UploadUnknown，保留字节/lease/身份；重开先 Query，同任务若 done 直接接收，不补 PUT |
| 上传恢复 | Query 明确 waiting-file | 明确恢复后核验同一原件与原租约，仅一次补传；生产图片/DOCX 总 PUT=2、POST=1 |
| 上传适配器 | HTTP 403/204、截断、SDK 异常、超时、失效租约 | 不确认上传成功，不泄漏 SDK 原始敏感详情，文件句柄关闭；失效租约 0 PUT |
| 云解析轮询 | Query 断网 | Paused，恢复 Query 同一 batch，POST/PUT 数不增加 |
| ZIP 结果接收 | 中途断网 | 不发布结果；保留清理预约，恢复先清理 part，再核原任务接收 |
| ZIP 预算 | 连续失败并多次明确恢复 | 图片/DOCX 最多三次接收，达到上限明确停止；不新建 POST |
| 结果流/磁盘 | 无结束事件、长度不符、超预算、写盘失败 | 不发布 Ready/Received；只清理自己 part，关闭句柄，保旧内容 |
| 结果关联/登记 | 错 task/data/hash；登记写入失败 | 不发布假结果，登记失败保预约与原件，恢复仍使用原任务 |
| 统一快照 | write/fsync/rename 失败、物理读回损坏 | 保上一活动记录，故障资产不标 Ready，可按持久账本本机恢复 |
| 正文发布 | chunk 写入失败/CAS 失效 | 保旧代；本机重试消费已存快照，0 解析/嵌入请求 |
| 已收结果丢失 | 已收 ZIP/快照缺失 | 不冒可用，不自动重新解析；已有可读正文保留 |
| 图片理解 | 鉴权拒绝、网络未知、晚到结果 | 401 Failed；未知不自动重试；晚到自动结果不覆盖用户修正 |
| 向量入库 | 第三块请求中断；镜像/读回失败 | 2/6 未完整发布，明确重试只发未成功输入，成功读回复用；镜像失败不标 Synced |
| 准入/后台 | 持久 InFlight 后、launch 前切后台 | 当前进程可证明未 launch 时记 NotSent，可暂停恢复；真正网络 Unknown 不自动重发 |
| 设置/授权 | 拒绝许可、换凭据、停用 | 对应发送 0；已有任务可保身份，已撤销或变化的配置不放行 |
| 页面来源 | A/B 异步读回倒序、块 ID 相同 | 只采用最后打开文档，清旧首屏；key 绑定文档/代/块 |
| 本机副本删除 | 引用保护拒绝或持久成功 | 前者保留并反馈原因；后者移除词条、回执明确，不强删知识来源 |
| 检索/历史 | 语义失败、历史写失败、晚到页/配置变化 | 本机 Direct/tags 保留；不假成功，不以旧许可重发问题 |

以上来自正式服务/仓储/适配器在隔离 SQLite、内存文件和受控网络端口中的执行。不是模拟器真实断网、云端额度耗尽或物理断电结果。以正常/异常/拒绝/模型失败四类归档，既有回归与新断点测试共同覆盖。
