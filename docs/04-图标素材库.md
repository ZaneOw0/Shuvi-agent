# 04 图标素材库

> 状态：v0.2，品牌配色更新已通过开发者视觉审核和本轮模拟器人工检查（含最大字体），反馈日期 2026-10-09。v0.1 图标与 v0.2 配色记录分别见 [功能 spec 第 6.5、6.6 节](../specs/01-创建日程并提醒.md)，品牌方案见 [05 品牌配色与 Logo](05-品牌配色与Logo.md)。
> 范围：应用内的功能图标、统一显示组件、素材预览和复用约定。

## 1. 从哪里开始

用浏览器打开 [图标预览页](assets/icons/index.html)。本地双击即可使用，无需安装依赖或启动服务器；GitHub 文件页面不会直接运行 HTML。

预览页支持中文名称、资源名和用途搜索，按导航／功能／操作／状态筛选，查看 16、22、24、32 px 尺寸；点击卡片后可以选中并复制 ArkUI 引用示例。白色图标使用莓紫底展示。网页中的 px 仅用于预览，ArkUI 的默认布局尺寸使用 vp。

## 2. 唯一资源与目录

| 路径 | 职责 |
|---|---|
| `entry/src/main/resources/base/media/chat_*.svg` | 既有的 14 个图标，保留名称和图形 |
| `entry/src/main/resources/base/media/ui_*.svg` | 本轮新增的 9 个通用功能图标 |
| `entry/src/main/ets/components/AppIcon.ets` | 应用内统一的装饰图标 Builder |
| `docs/assets/icons/catalog.js` | 图标名称、分类、用途和批次清单 |
| `docs/assets/icons/index.html` | 团队可直接打开的预览页，引用应用中的原 SVG |

SVG 只在应用资源目录保存一份。预览页不复制图形、不调用在线图标服务、不加载外部字体。素材预览属于开发文档，不打包为产品页面。

## 3. 视觉约定

- 统一使用 `viewBox="0 0 24 24"`，1.7 单位描边，圆角端点与连接，空心线条风格。
- 常规图标默认显示 22 vp；辅助提示 16–18 vp；顶部和输入区按现有布局使用 22–26 vp。
- 功能列表采用 42 × 42 vp 的淡紫底容器，图标居中显示。该容器不是独立点击区域，整行 Button 接收点击。
- 品牌配色：正文描边 `#342638`，强调 `#793B68`，辅助 `#796A76`，深色按钮上的反白 `#FFFFFF`。常规图标用正文色，关闭和进入箭头用辅助色，导入用反白。
- SVG 自带描边颜色，当前不提供任意染色接口，不在页面上用 `fillColor` 覆盖空心图形。
- 重要功能保留文字名称与“待接入”说明，不能只通过图标或颜色表达状态。
- 独立图标按钮保留至少 44 × 44 vp 的点击区域，由外层 Button 提供 `accessibilityText`。AppIcon 本身不单独朗读，避免与按钮或相邻文字重复。
- 角色 Logo 属于品牌素材，与功能图标分开管理，详见 [品牌配色与 Logo](05-品牌配色与Logo.md)；[应用内悬浮助手入口](../specs/02-应用内悬浮助手入口.md)复用 `BrandAvatar`，不增加一份图标资源，验收独立记录。

## 4. 在 ArkUI 中使用

在需要显示图标的文件顶部引入组件，相对路径按文件位置调整：

```typescript
import { AppIcon } from '../components/AppIcon';
```

在 `build()` 或 `@Builder` 内：

```typescript
AppIcon({ source: $r('app.media.ui_folder'), size: 22 })
```

只有图标的可点击入口示例：

```typescript
Button({ type: ButtonType.Circle }) {
  AppIcon({ source: $r('app.media.ui_close'), size: 22 })
}.width(44).height(44)
  .accessibilityText('关闭导航菜单')
  .onClick(() => this.drawerOpen = false)
```

上述事件示例用于已有 `drawerOpen` 状态的页面。AppIcon 只负责绘制，不包含导航、网络、权限和业务状态。

## 6. 新增与维护

1. 先检索素材库，有相同含义时复用。
2. 通用新增资源使用 `ui_<英文含义>.svg`，不要使用含糊编号。既有 `chat_*` 暂不批量重命名，避免无关改动。
3. 按上述网格、线宽和颜色规则编写 SVG，只保留图形元素；不嵌入脚本、外部链接或位图。
4. 在 `catalog.js` 增加名称、用途、分类、颜色背景和批次，更新本页清单；预览页直接读取元数据。
5. 检查小尺寸辨识度、浅底／深底对比、文字与点击区域，再运行 Code Linter 和构建。
6. 在模拟器中检查使用页面并记录验收；构建和网页预览不能替代 ArkUI 设备显示结果。

新增 9 个 SVG 为本任务直接编写的几何图形，未引入第三方图标包；原有 14 个 SVG 沿用仓库图形，本轮统一更新描边色。未来引入外部素材时，在本页登记作者、来源和许可，并保留要求的署名。

## 7. 本轮审核重点

- 工作台：五个入口能辨识，点击行为与原先一致。
- 知识库：导入、检索、文档与阅读图标正常显示，固定样例和待接入说明仍清楚。
- 我的：设备、外观、关于入口正常显示。
- 助手：原有图标与确认卡片正常，侧栏关闭按钮仍可点击。
- 字体放大后文字可换行，图标不挤压文字或遮挡操作区域。
