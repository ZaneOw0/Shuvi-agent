# T53：协作策略接入与本机验收

日期：2026-10-19。状态：实现及本地主机验证完成，待人工审核；尚未提交。

## 范围与调用链

本轮实现 M13-D 适配骨架，沿用 M11 `ArtifactPolicyReleaseRunner` 和现有 `CollaborationPlan`。默认 `learnedEnabled=false`，没有加载 MasRouter 权重、训练、下载模型、调用真实 Provider、激活生产 artifact、签名或操作设备。fake 只证明控制流；T54 继续暂停，S9 未关闭。

`AgentRuntimeFacade → RuntimeCoordinator → 有总时限的 prepare → M11 baseline/shadow/canary/active → 校验候选 → 同步 selectPlan → 持久化完整激活占用 → Planner`。

- `routing/CollaborationPreparation.ets`：可选准备端口与整个阶段的时间上限，包含 loader 等待，默认 5000 ms；超时取消子信号并忽略迟到结果。
- `routing/ArtifactCollaborationPolicy.ets`：默认关闭的适配器、loader/evaluator port、内部候选 DTO。关闭时不读取 release view、不调用 loader。
- checkpoint 1.2 增加准备状态和决策次数；预算继续使用原有 `usage.agentActivations`，没有另建一套预算账本。

候选必须绑定 task、完整 TaskFrame 摘要、Role/Model Registry 摘要和 artifact 摘要。校验版本、有限置信度、非负整数成本、最多 6 个有序角色、角色去重、角色/模型 ID/版本/digest 和完整 activation budget，再调用 `CollaborationPlanValidator`。模型身份仅是建议，不产生 Provider 调用权或授权 grant。

缺 artifact、加载/评估异常、超时、低置信度、非法数值、越界角色/模型及预算不匹配回退 deterministic Single。Single baseline 自身无效时终止规划，不伪造成功。缓存绑定输入、预算、Registry 和 generation，返回防御性副本。

## 宿主组合

composition 从 2.5 升为 2.6；`AgentRuntimeFacade` 方法与同步 `selectPlan` 签名保持不变。

```typescript
const policy = new ArtifactCollaborationPolicy(
  roles, models, digest, releaseRegistry, loader, canaryAssignment,
  new ArtifactCollaborationPolicyConfig()
);
ports.collaborationPlan = policy;
ports.collaborationPreparation = policy;
```

两个端口必须引用同一个实例，否则拒绝组合。内置 artifact selector 漏接 preparation 也拒绝。MCP、Provider MCP、RDB 组合透传同一实例；同时修复 RDB 原先漏传 `collaborationPlan` 的问题。

宿主 digest port 应提供真实 SHA-256，FakeDigest 仅用于测试。release view 应来自既有 M11 Registry；fake active view 只在测试内构造，没有向真实 Registry 发布。

loader/evaluator 是宿主扩展边界，本轮没有新增文件解码器、Python 或模型推理环境。内部 DTO 不直接等于 T52 HANDOFF.json：离线 checker 负责交接包准入，未来 loader 将已准入产物映射到内部候选。内部 confidence 为 0–1，T52 basis points 需显式换算。真实 loader、encoder/embedding、checkpoint parity 和质量验证仍未完成。

## 取消、预算和恢复

- 校验通过且没有已知或排队 command ID 冲突的取消请求，先中断对应任务的准备计算；状态、回执和持久化仍走 FIFO。错误任务 ID 或无效命令不能中断其他任务。
- shutdown 中断准备并在队列内取消受影响任务；中断后不调用 Planner/Adapter。这里只验证 fake 取消与迟到隔离，不证明真实网络资源已经释放。
- 每任务初判一次，最多再评估一次；之后的规划只走 Single baseline，不重新调用策略。
- Planner 调用前保守占用完整 assignments 并持久化，失败或中断不退还额度；它不是实际完成的模型调用数。澄清后的 Planner resume 也再次占用额度。
- checkpoint 1.2 保存 evaluations、pending、baselineOnly；恢复不重置激活计数和重判次数。
- 1.1 只接收 Single，迁移为 baselineOnly 并耗尽策略评估额度；旧 MULTI 拒绝。pending 的 1.2 返回 `PREPARATION_REQUIRES_RECONCILIATION`，不自动重跑。宿主必须处理这个受控恢复失败，本轮不实现人工恢复页面。
