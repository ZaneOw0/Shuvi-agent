版本以各 `oh-package.json5` 为准，来源与本地修改见 [模块目录](../../modules/harmony_agent/README.md)。日历、文件和知识库的产品工具由 entry 应用适配，模块可用不代表所有平台场景已验收。

## 2. 依赖与分工

entry 负责宿主装配、应用服务和平台适配，模块通过公共出口协作，核心不依赖 UI。UX 维护交互和状态；Agent 维护规划、任务与公共契约；平台维护系统资源、设备与工具链；RAG 维护检索、文档/来源身份和索引生命周期。

上游 M/T 编号保留在 [固定归档](../archive/README.md) 用于追踪设计与任务，不作为当前必须一一对应的工程目录。研究策略和多 Agent 产品协作尚未完成验收。
