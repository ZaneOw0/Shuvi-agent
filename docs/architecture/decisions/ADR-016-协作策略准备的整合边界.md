# ADR-016：协作策略准备的整合边界

> 状态：已实现待验收（继承上游已实现设计；本轮未开启生产 learned 策略）。
> 更新日期：2026-10-23。来源：`f177176`，保留上游 ADR 编号。

## 背景与选择

上游同步 `selectPlan` 接口无法直接等待异步策略加载。已采用可选异步准备端口，在 Runtime 规划流程中完成有界准备，再由绑定的同步 selector 消费经校验的候选。保留 Facade 控制入口，不让 loader 直接推进任务。

## 理由与代价

这种方式保留已有同步调用方，并让超时、取消、任务身份和预算仍由 Runtime 管理。代价是需要维护准备器/selector 成对装配、迟到结果失效、检查点版本兼容和组合路径透传。策略失败可以按规则回退 Single；整个任务取消后不能借回退继续调用 Planner。

## Shuvi 适用范围

本次源码迁移保留实现与测试，不开启 learned 路径，不导入训练权重，不发布 active 研究策略。八模块 Hypium 回归包含该固定版本的相关测试；真实服务取消、目标设备恢复及生产策略效果仍需单独验收。
