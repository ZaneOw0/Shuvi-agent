## 实际行为

启用普通真实对话后，模型通过标准 `tool_calls` 自主选择文档工具，宿主校验参数并交给 Native Runtime 执行，将结果按 `tool_call_id` 送回模型。没有固定指令语法、额外工具页面或按钮。搜索、RAG、视觉对话保持原有范围。

| 模型工具 | 参数 | 行为 |
|---|---|---|
| `document_create` | fileName、content | 创建 UTF-8 txt/md，并保存至 Download |
| `document_read` | fileName（或文档 ID） | 读取正文、版本与真实保存位置 |
| `document_update` | fileName、expectedVersion、content | 校验版本后更新完整正文并保存至 Download |

保存位置为系统文件管理器的 `Download/com.example.shuvi/<fileName>`；文件管理器可能把该应用目录显示为“休比”。工具返回 `savedToDownloads`、`storageLocation`、`fileUri`，写入答案附真实版本、保存位置和回执。仅支持应用管理的 txt/md 文档，每份不超过 256 KiB；不接受任意路径。尚无删除工具。

旧私有文档读取时明确返回尚未保存至 Download；用户要求保存时，模型先读取，再 update 完整正文。启动时不批量导出旧文档。同名陌生文件或检测到外部修改时拒绝覆盖。

模型对话使用 PERSONAL 会话。用户在现有启用说明中授权所选正文和对话发送到 `api.deepseek.com`；凭据仍只在应用输入，退后台/关闭时清除。公开 Download 文件可被其他应用访问，范围已写入启用说明。没有新增权限或外部依赖，只新增已有 native_tools 本地 HAR 的产品引用。

独立文档加密库为 `shuvi_documents_execution_v1.db`。grant 严格绑定 task/step/operation/attempt/invocation、用户、策略、工具身份、schema、参数摘要、预算和有效期；没有默认放行授权。私有版本和持久化记录继续保留，用于版本/冲突与不确定结果核查。

## Download 平台方式与失败语义

使用官方 `DocumentViewPicker` 的 DOWNLOAD 模式，无文件选择界面，得到应用所属目录的持久 URI。依据：[保存用户文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/save-user-file)、[DOWNLOAD 文件访问](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-local-file-manager-67)。

用户实测中，公共目录的 rename 返回 `13900012`（权限拒绝），因此当前实现先在授权目录暂存并 fsync/核对摘要，再提交私有不可变版本及 CAS 回执，打开目标文件，通过源/目标 FD 复制、fsync、关闭并读回校验。暂存失败不增加内部版本。

公开文件替换不具备原子性，也没有跨应用事务 CAS。私有提交后复制失败或被取消，目标可能不完整；保留私有历史正文，返回不确定并禁止本轮继续写入，允许真实 document_read 核查，不自动重发。旧的原始 DSML 调用文本不会执行或原样充当工具结果。错误只记录阶段、数字系统错误码、privateCommitted 和时间，不记录正文、路径或凭据。

每轮最多 6 次模型响应、6 次工具调用，累计最多 8192 input / 1024 output tokens；每次启用最多 10 次实际模型请求，工具轮次最长约 120 秒。上下文最多保留 8 轮，离开/关闭会话后清除。真实工具结果与失败提示由宿主补充，不能用模型文字掩盖失败。

## MCP 写入兼容

保留现有 `requiredToolIds` 参数；Native 工具扩展追加在其后，不替换原参数。写工具要求显式策略、工具目录匹配、风险/副作用/边界检查、授权和幂等绑定；允许与只读 MCP 混合派发并转发取消。

写 profile 必须禁用 `retryToolCallOnExpiredSession`，否则以 `MCP_WRITE_SESSION_REPLAY_ENABLED` 拒绝，避免会话恢复重放写入。只读调用保留上游旧会话恢复和取消能力；结构化失败与可能已提交的 UNKNOWN_OUTCOME 分开处理，不自动重放。已有搜索结果持久化与待核账约束保留。

导入基线 `UPSTREAM.json` 不变；产品源码增量及 native_tools 的产品引用登记在 `modules/harmony_agent/LOCAL_CHANGES.json`，本次账本不包含未提交的测试增量。
