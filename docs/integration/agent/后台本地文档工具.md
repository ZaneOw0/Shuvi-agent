# 后台文档工具接入

## 1. 当前接口

| 工具 | 参数 | 结果 |
|---|---|---|
| document_create | fileName、content | 创建 UTF-8 TXT/MD 并保存 Download |
| document_read | fileName 或文档 ID | 正文、版本与真实保存位置 |
| document_update | fileName、expectedVersion、content | 校验期望版本后更新完整正文 |

模型通过标准 tool_calls 选择工具，宿主校验后交由 Native Runtime，按 tool_call_id 回填结果。聊天回执展示文件名、版本和保存位置，无额外工具页面；不提供任意路径或删除工具。

## 2. 装配与授权

`DocumentToolContracts` 定义模型工具，生产应用组合装配平台执行资源。Registry、授权、参数摘要、幂等键、持久化派发与取消约束贯穿整个写入；日程提议与文档工具共享助手会话，各自校验操作。

用户启用时知悉正文发送给 DeepSeek，以及 Download 的公开文件位置。旧私有文档不在启动时批量导出，需要时先读取再显式更新。

## 3. 文件与失败语义

每份正文不超过 256 KiB。DOWNLOAD 模式取得应用下载目录，保存到 `Download/com.example.shuvi/<fileName>`；模型不可指定任意目录。私有不可变版本与加密操作记录用于恢复和核查。

公开写入先暂存、同步和摘要核验，再提交私有版本，通过 FD 复制、同步、关闭与读回发布。检测同名陌生文件、外部修改或期望版本冲突时拒绝覆盖。公开替换不具有跨应用原子 CAS；私有提交后公开写入异常报告不确定，保留私有正文并限制后续写入，允许真实只读核查。

## 4. 验证

覆盖创建/读取/更新、冲突、取消、授权拒绝、持久化失败与未知结果；模型文字和 DSML 不作为真实工具调用。

主机入口为 `entry/src/test/run-direct-model-tests.cjs`，设备真实 Download 与异常路径需对应版本证据。整体集成记录见 [三链路回归](../../verification/PR26-main合入与RAG三链路回归.md)，当前用户契约见 [文档工具](../../../specs/09-后台本地文档工具.md)。
