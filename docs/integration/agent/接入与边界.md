## 1. 应用入口与生命周期

当前可查看 [Runtime 导出](../../../modules/harmony_agent/agent_runtime/Index.ets) 和 [Shuvi 应用组合](../../../modules/harmony_agent/agent_connectors/src/main/ets/provider/ShuviWebSearchApplicationBackend.ets)。应用宿主装配一次，页面通过应用服务提交、订阅和取消任务，不能每次重绘重建 Runtime。

通用 `createSingleAgentHostRuntime` 按凭据 → 执行存储 → 记忆存储 → MCP 顺序打开资源，再创建 Facade；失败时回滚。关闭先处理 Runtime，再逆序释放资源；页面离开不等于整个 Ability 关闭。生产配置不能用空资源、全允许授权或零价格占位来满足必填项。

新增的 [普通对话范围](../../../specs/09-Runtime普通对话接入.md) 使用独立应用装配：实际凭据、加密对话执行库和模型 Transport 均存在；明确禁用记忆查询与 MCP 连接，这两项生命周期资源不承担数据读写/网络职责，且没有任何可派发工具。它仅代表单轮模型对话，不能作为搜索宿主、完整记忆或工具授权已实现的证据。现有搜索启动检查继续使用真实搜索资源并禁止任务。

## 2. 模型与网关

`ModelTransportPort` 定义模型请求传输边界；Connectors 中已有 [LocalAIGatewayTransport](../../../modules/harmony_agent/agent_connectors/src/main/ets/provider/LocalAIGatewayTransport.ets)。当前 [Shuvi 搜索组合](../../../modules/harmony_agent/agent_connectors/src/main/ets/provider/ShuviWebSearchLocalAIGatewayRuntime.ets) 使用该路线，仍须提供实际模型目录、价格快照、凭据与资源实现。

Gateway 位于 `services/local-ai-gateway/`，运行在 Windows x64，不进入手机包。换成服务器或设备直连模型，需要实现、注入并验证对应传输，不是改一个地址就完成 OpenHarmony 迁移。手机上的 `127.0.0.1` 指手机自身；电脑服务地址与调试转发由平台侧明确配置。

电脑 DeepSeek 文本探针已成功的历史记录不能替代 Planner 测试：现有 ArkTS Transport 尚无该探针使用的 `extra_body/thinking` 映射，Planner 还要求受约束输出。完整缺口见 [B2 前置核对](../../06-Agent模块接入.md#6-b2-宿主装配前置核对)。

## 3. MCP 协议与工具授权

手机使用自有 ArkTS MCP Client，不把 Node SDK 打进 HAR。固定源码包含 MODERN、LEGACY、AUTO 模式；其实现分别处理 `server/discover` / `2026-07-28` 和 `initialize` / `2025-11-25`。这些是导入版本的实现声明，不是对协议最新标准或所有第三方服务的兼容保证。

只有明确的不支持发现响应才允许回退；认证失败、超时和畸形响应不能靠降级绕过。工具调用不自动重试。受控目录、工具身份、Schema、参数摘要与 Runtime grant 必须匹配；远端 annotations 不替代本地只读 allowlist。

代码入口见 [MCP Client 导出](../../../modules/harmony_agent/mcp_client/Index.ets)、[Connectors 导出](../../../modules/harmony_agent/agent_connectors/Index.ets)。协议原理和历史验收见 [归档协议说明](../../archive/harmony-agent-f177176/docs/PROTOCOL_IMPLEMENTATION.md)，当前 fixture 验证与设备证据分开记录。

## 4. 联网搜索接入

`services/search-mcp/` 提供真实 `web_search` 服务和不调用供应商的 discovery 模式。连接检查仍只验证握手和目录；2026-10-24 另增 debug 首页真实搜索：关键词 → 实际参数授权 → 持久化派发 → MCP → 保存来源及待核账记录 → 独立 Runtime 模型任务回答。原 Mock 模式保留。

装配见 `SearchRuntimeAssembly.ets`，会话见 `RuntimeSearchSession.ets`，持久化与 grant 校验见 `SearchExecutionResource.ets`。使用确定性关键词计划，不是自主语义规划。用户批准一次未核账派发，配置账户标签 `shuvi-dev-tavily`、币种 CNY；本地 CNY 1.00 预留不是实际费用。重启限额、异常及仅重试回答规则见 [spec 03 §6.11](../../../specs/03-联网搜索.md)。真实账单与额度释放未实现。

2026-10-23 应用层已增加授权预览包装器：利用公开的工具准备端口保留实际搜索参数，按授权请求身份和摘要关联前端 DTO，批准前再次检查有效期；没有更改固定模块。通用模型装配入口已安装该包装器，页面仍未启用真实模式。规则与后续宿主接线见 [联网搜索 spec 4.4](../../../specs/03-联网搜索.md#44-真实授权预览的应用层准备2026-10-23)。

对照入口：[ShuviWebSearch](../../../modules/harmony_agent/agent_connectors/src/main/ets/mcp/ShuviWebSearch.ets)、[服务说明](../../../services/search-mcp/README.md)、[上游搜索接入原文](../../archive/harmony-agent-f177176/docs/SHUVI_WEB_SEARCH_MCP_INTEGRATION.md)。

## 5. 存储、凭据与恢复

执行存储负责检查点、授权和操作恢复；记忆存储负责长期记忆及可重建索引。RAG 检索与记忆的检索/更新边界需要共同定义，不能直接操作执行库或假定已共享索引。

[AssetStore 适配器](../../../modules/harmony_agent/agent_connectors/src/main/ets/provider/AssetStoreProviderCredentialPort.ets) 包含受控查询和凭据管理能力；[加密 RDB 生命周期](../../../modules/harmony_agent/agent_storage/src/main/ets/integration/EncryptedRdbLifecycle.ets) 提供打开、换钥封装。宿主仍要决定别名、密钥来源、访问条件、轮换失败与关闭策略。导入 API 不等于已在产品启用或已验证真实数据迁移。

设备测试会操作固定测试别名与数据库，必须用隔离宿主。原文分别见 [凭据](../../archive/harmony-agent-f177176/docs/AGENT_ASSET_CREDENTIAL_STORE.md)、[加密配置](../../archive/harmony-agent-f177176/docs/AGENT_ENCRYPTED_RDB_CONFIGURATION.md)、[恢复桥接](../../archive/harmony-agent-f177176/docs/AGENT_RUNTIME_STORAGE_INTEGRATION.md)、[记忆](../../archive/harmony-agent-f177176/docs/AGENT_MEMORY_CONTEXT_INTEGRATION.md)。其中历史版本和测试数量不作为本轮证据。

## 6. 本地工具与策略产物

`native_tools` 目前提供只读电池能力，且只进入测试工程。没有因此实现日历创建或提醒送达。接入新的 Native Kit 工具需按平台规范说明 API、权限、数据归属和验收。

Artifact 注册/加载和协作准备沿用原接口；研究权重与离线训练目录尚未导入，不启用生产 learned 策略。对应 [ADR-016](../../architecture/decisions/ADR-016-协作策略准备的整合边界.md) 与 [工具处理清单](../../../tools/agent/迁移清单.md) 明确边界。
