# Agent 接入与边界

## 1. 应用入口

应用宿主持有实际凭据、执行存储、记忆、时钟与平台资源。页面通过应用服务发送、订阅、授权和取消，不在重绘中重建 Runtime，不访问模块内部 Coordinator。

AgentRuntimeFacade 是公共任务控制入口；通用宿主组合管理资源打开、失败清理与逆序关闭。活动会话在后台或停止时取消，前台不自动重发旧操作。

## 2. 模型与工具

主助手通过 DeepSeek 直连适配器驱动统一工具循环，按意图调用文档、日程提议、搜索和知识库工具。搜索使用 Tavily 手机直连；独立 Windows 网关及 MCP 搜索路线保留在子项目，不是当前手机主链路的前置服务。

模型的 tool_calls、参数和结果经运行时校验，再由 Registry / Runtime 约束身份、授权、预算和持久化派发。仅工具目录可见不授予执行权；日程提议还需用户确认后写系统日历。

## 3. 协议与平台

ArkTS MCP Client、供应商连接器和原生工具提供不同执行适配；固定协议实现及版本以模块源码和 UPSTREAM 清单为准，不把其声明扩展为所有第三方服务兼容性。

日历、文件、媒体与知识库由应用平台适配器接入。手机上的回环地址指向手机自身；当前模型和搜索主链路无需电脑端口转发。

## 4. 数据与费用

Key 由安全存储和会话凭据管理，不进入日志、来源或仓库。普通记忆、知识库权威内容、搜索执行记录、日历操作与文档版本分别持久化。

搜索用量/本地预算与供应商实际账单分别管理，见 [账单契约](搜索账单与结果持久化.md)。结果未知、持久化失败和取消按真实状态处理，不自动结算为零费用或伪造成功。
