# 知识库回答 UI 契约

> 状态：主助手 L2 已接入待验收。独立知识库页面的检索会话继续保留。

## 1. 调用入口

主聊天通过 `RuntimeChatService.session.send` 发送消息，`RuntimeKnowledgeService.session` 提供知识库授权与来源状态。前端不直接调用 Provider、Runtime 内部、向量库或仓储。

启用知识库时说明命中片段将发送给 DeepSeek，并单独选择是否允许语义查询。不开启时不提供 `knowledge_search`，开启后由同一模型按需决定调用。不要创建第二个 Key 输入或独立回答模型会话。

## 2. 状态与来源

页面展示授权、打开/查询/回答进度、失败原因、引用和取消入口。后台引用是本轮绑定的 KnowledgeRuntimeCitation，卡片保存文件 ID、generation、标题、类型与引用编号。

`ChatKnowledgeSources` 只对真实绑定且编号完整的来源段生成卡片；历史恢复验证 v1 快照，不依赖当前检索结果。同文件引用合并，超过 3 个文件可展开；来源段后跟网页来源仍显示卡片，网页文本保留。

打开卡片前核对文件存在、未归档/删除且 active generation 相同；不可用时明确说明，不打开另一个版本冒充原来源。

## 3. 授权与记忆

取消、撤销、停止、后台或换对话使本轮授权结果失效。普通模型记忆可持久化；知识库来源及其派生后续上下文仅在当前授权会话临时使用。历史 UI 快照不自动变成模型记忆或新外发授权。

语义不可用时标记真实降级，未检索、证据不足与模型失败分别呈现。每轮最多 2 次知识查询，累计 5 条 / 3200 字符；模型请求和会话限额见 [L2 契约](../../specs/11-主对话Agent知识库L2检索增强.md)。

## 4. 前端验收

覆盖授权取消/拒绝语义、普通问题不强制查库、引用与文件合并、搜索混合来源、历史恢复、来源换版/归档/删除、查询中撤销、换对话和后台取消。最大字体、读屏和真实模型质量须单独验证。

证据见 [L2 实施](../verification/主对话L2实施记录.md)、[集成回归](../verification/PR26-main合入与RAG三链路回归.md) 与 [补丁验证](../verification/发布前补丁验证.md)。
