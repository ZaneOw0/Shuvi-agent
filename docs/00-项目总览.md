# 00 项目总览

休比（Shuvi）是面向 HarmonyOS 手机和平板的智能个人助理，ArkTS / ArkUI 开发。当前产品由统一助手、日程、个人知识库与本机配置组成，处于真实能力整合与验收阶段。

## 1. 产品目标与需求

理解文字、图片和语音表达的个人事务需求，结合资料与外部信息生成可追溯回答，或在确认与授权后执行真实操作。需求优先级由团队维护，已实现范围见 [项目进度](08-项目进度与验收.md)。

| 优先级 | 功能 | 当前需求说明 |
|---|---|---|
| P0  | AI 对话 | 集成 AI 导航与 App 使用说明 |
| P0  | 文件管理 | 具体范围在功能 spec 中细化 |
| P0  | 日历日程 | 集成系统提醒与备忘录 |
| P0  | 构建个人知识库 | 支持个人知识库离线检索与问答 |
| P0  | 联网搜索 | 具体范围在功能 spec 中细化 |
| P0  | 多模态输入和交互 | 支持文字、图片、语音，理解复合指令 |
| P0  | 多设备适配和登录 | 支持多设备适配与登录 |
| P0  | 主题切换与自定义 | 支持主题切换与自定义 |
| P1  | 跨设备协同 | 流转任务和上下文 |
| P1  | 智能体编排 | 至少 3 个子 Agent 协同，自主分解复杂任务 |
| P1  | 长语音转写 | 录制或上传长语音音频，提取原文转写与 AI 摘要 |

## 2. 当前架构

`ArkUI → 应用服务 → Agent Runtime / 模型工具循环 → 授权与校验 → 工具执行 → 平台适配`

| 落点 | 职责 |
|---|---|
| entry | 页面、生命周期、模型会话、知识库、日历/文件/媒体适配与装配 |
| Agent HAR | 公共契约、执行内核、Runtime、连接器、协议、存储与原生工具 |
| 独立测试宿主 | Agent 设备测试与故障场景，不进入产品 |
| 独立服务 | Windows 模型网关与搜索 MCP，和手机 HAP 分别运行、构建 |

主助手设备直连 DeepSeek，搜索直连 Tavily。知识库 L0/L1 与授权下 L2 共享检索底座；统一工具循环支持文档与日程提议。日程写入等待用户确认，其他工具遵守相应授权范围。

核心不依赖页面与具体适配器，页面不直接操作模型、系统日历或内部仓储。模型输出、网络数据与工具参数运行时校验，失败状态与实际副作用分开记录。

## 3. 数据与授权

原件解析、图片理解、入库向量化、查询向量化、回答片段与搜索关键词各有明确外发范围。关闭授权停止后续使用，已产生的供应商费用与远端副本按真实结果报告。

普通对话记忆本机持久化，知识库上下文仅在当前授权会话消费；系统日历、Download 文件、知识库权威内容、索引、执行账本和 UI 快照各自管理。

## 4. 交付目标

完成正常、异常、权限拒绝和模型失败路径，分别留存 host、构建、模拟器及真机证据。尚未完成的多设备登录、跨设备协同、主题自定义、长语音、通用文件管理与多 Agent 产品协作继续保留为需求，不据现有局部能力宣布完成。
