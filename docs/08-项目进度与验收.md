## 3. 当前阻碍和剩余工作

1. 平台确认目标 OpenHarmony 设备/SDK，以及网关部署位置、凭据和模型资源。当前 HarmonyOS API 26 证据不能替代 OpenHarmony 验收。
2. Agent 与 UX 对齐真实待执行参数的授权展示、澄清回复、回答重试，以及模型 thinking/结构化输出支持；已有接口不能用猜测或假参数补齐。
3. 平台核对 runner 的 API 26 SDK 路径、Node 24、.NET 10.0.302、CODELINTER_LOG_DIR；处理 Code Linter 规则分派/分析异常，并与 Agent 共同复核 await 和深拷贝诊断。没有完整 lint 证据前不宣称全部门禁通过。
4. 设备编排与发布工具存在旧路径/包名/清理行为，按 [迁移清单](../tools/agent/迁移清单.md) 逐项适配；离线研究数据、权重与许可证单独审查。
5. 在隔离设备完成网络取消/错误、恢复、凭据和加密库测试，再完成真实产品闭环与团队评审。
