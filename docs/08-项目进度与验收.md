# 08 项目进度与验收

当前阶段为真实能力整合与发布前修补。本文汇总当前工作树的能力与剩余验收，具体时间、提交、设备和复现命令在 [验收记录](verification/README.md) 中维护。

## 1. 当前实现

| 功能 | 已实现范围 | 待完成或待验收 |
|---|---|---|
| 主助手 | DeepSeek 直连，同一模型工具循环、取消与状态投影 | 真实意图质量、完整错误与恢复矩阵、账单和正式发布 |
| 多模态 | 文字、单图、普通话语音与补充文字；图片私有副本与附件折叠 | 图片/语音/工具组合的完整设备验收、图片孤儿副本与录音管理 |
| 日程 | 草稿提议、卡片编辑、确认写入、读回、工作台多条记录与核查 | 权限拒绝、未知结果恢复、提醒送达和真机 |
| 搜索 | Tavily 手机直连、本对话授权、每轮最多 2 次调用、网页来源与满库清空 | 完整真实设备场景、费用核对、正式包开放 |
| 知识库处理 | TXT/MD、PDF、图片、DOCX；原件、规范化内容、图片描述/标签和向量队列 | PPTX/XLSX、完整质量/性能矩阵与真机 |
| 知识库检索 | 统一 L0 FTS/字面路径，L1 合格空间语义查询，主对话自主 L2 与来源卡片 | 设备 tokenizer/FTS、冷启动及跨页质量、异常恢复 |
| 知识库 UI | 资料/正文/图片分页，固定高度任务分页，跨页重试未完成 | 任务分页/批量重试的设备验收，最大字体与读屏 |
| 历史对话 | 普通模型记忆与摘要、本机消息、图片副本及来源快照 | 长历史摘要设备触发、异常与真机矩阵 |
| 手机平板 | 同一 HAP，抽屉/侧栏响应式、横竖屏与键盘布局 | 更大字体/窗口组合、目标硬件及 OpenHarmony |
| Agent / 网关 | 八 HAR、独立宿主、固定来源和本地扩展；独立 Windows 网关及测试 | 完整平台集成、多 Agent 产品协作、网关运行包与部署 |

多设备登录、跨设备数据/上下文协同、主题自定义、长语音和通用文件管理仍属于 [产品目标](00-项目总览.md)，当前局部能力不覆盖这些完整需求。

## 3. 发布前剩余工作

1. 对最新版本完成有效的静态检查、完整 CI 与相关回归；分析器异常和扫描覆盖缺失保持失败处理。
2. 补齐真实权限拒绝、取消、断网、未知结果恢复和供应商账单证据；不重复收费请求来代替已有证据整理。
3. 在目标手机、平板与 OpenHarmony 设备验证兼容性、来源、日历提醒、无障碍与性能。
4. 排查大型知识库首次打开的明显等待，保留用户资料和已有索引/向量。
5. 按产品优先级推进未实现目标，工具授权、数据迁移与公开契约变化先评审。
