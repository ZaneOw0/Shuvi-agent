# Feature Specification: M1 文本知识库 L0 全链路

**Created**: 2026-10-12
**Status**: 需求审核中，尚未授权实现
**Input**: 按当前 spec 分阶段打通全链路；txt/md 先复用 `entry/src/test/fixtures`，验证其他格式时再补充真实测试语料。
**权威总契约**：`specs/02-个人知识库问答.md`（五稿）。本执行规格只映射 M1，不替代总契约。

## Overview

把固定样例探针扩展为真实 txt/md 用户闭环：原件保存、结构解析、分块、本机关键词检索、原文定位、文档管理、取消/重启恢复及 L0 查询历史。仅实施 M1，不接真实 embedding、LLM、MinerU、视觉服务或 AGC；伪向量与 Mock 不能成为用户链路完成证据。

用户已确认新用户库与旧探针隔离、所有既有资料保留、`entry` 内分层、不新增模块/依赖/权限，并批准本执行目录与总 spec 的 M1 范围/真实证据更新。txt/md 先完成其文件、资源、数据保护和固定语料门禁；外部服务 M0 到对应格式/外发阶段再完成，不取消任何隐私/原生定位/质量要求。

## User Scenarios & Testing

### 用户故事 1：真实导入、关键词查询与原文核对（P1）

用户选择 txt/md，看到处理状态，成功后用资料中的词句检索，并在原文详情核对命中位置，无需网络或模型。

**优先原因**：最小可用知识库闭环，代替固定语料自检。
**独立测试**：现有 fixture 文件通过真实选择流程导入，用预先标注的词句查询并查看原文。

**验收场景**：
1. 给定允许的 txt/md，经选择导入后原件字节一致，状态逐文件准确，命中可核对原文行号/范围。
2. 给定资料中存在关键词，返回真实命中/实际通道，不显示伪造语义、生成或相关度档位。
3. 无召回提示无相关内容；查询失败/超时单独提示，不能视为无答案。
4. 取消选择无副作用；不支持格式、类型伪装或非法编码明确报告，不把二进制硬读文本。

### 用户故事 2：Markdown 结构与 Unicode 边界安全（P1）

标题、列表、代码、表格和图片引用保留关系；规范化后的片段可准确映射原文。

**优先原因**：解决现有标题与正文分离、字符/定位缺陷，为复杂格式保留统一结构基础。
**独立测试**：现有 Markdown/Unicode fixtures 与构造边界用例，核对结构、标题/表头关联和原文范围。

**验收场景**：
1. 多级标题跟随正文，不产生仅标题且缺正文支撑的证据块。
2. 长代码/列表/表格有界分块，保留类型和父关联；表格保留表头、单元格关系及原文位置，不只存平铺文本。
3. UTF-8 BOM、CRLF/LF、非 BMP 字符规范化不丢有效内容，原文映射正确，不在代理对内部切分。
4. 图片外链/相对引用及样本中的命令只作原文内容，不联网、不读未授权文件、不执行。

### 用户故事 3：文档管理与安全重建（P1）

用户重命名、重建索引、归档/恢复、删除单篇/批量或清空自己的知识库，范围可见且不影响探针或设备其他资料。

**优先原因**：真实资料导入必须同时具备安全管理与删除。
**独立测试**：导入样本后逐项管理，核对文档、命中、原件、活动版本和清理状态。

**验收场景**：
1. 重命名不变原件/身份；重复原件导入不重复建库。
2. 归档独立于处理/索引状态，默认排除、可显式包含；恢复只撤销标记，未完成内容不变就绪。
3. 重建从已有快照进行，不上传；新版本校验通过前旧已发布索引仍可查，失败不破坏旧结果。
4. 删除需确认，提交后不再命中；文件清理失败单列待清理、可恢复，不回滚已提交删除。清空不触及探针或外部原文件。

### 用户故事 4：取消、中断与重启后的资料保留（P1）

用户可暂停处理，退出/重开后查看已有资料与任务，并从已保存原件恢复，不必重新选择原文件。

**优先原因**：消除进入页面即清库的破坏性行为。
**独立测试**：在导入/索引/重建/删除清理阶段制造明确中断或故障，重开核对检查点、完成资料和清理任务。

**验收场景**：
1. 进入/离开知识库或重启不自动清空，不导入固定语料，不触发伪向量/模型自检。
2. 取消保留已完成资料；已保存原件可手动恢复，未完成内容不显示就绪。
3. 重建中断保持旧活动索引有效，恢复仅发布一致的新版本。
4. 删除后晚到结果不复活文档；启动对账完成孤儿/待清理工作，不误删其他资料。

### 用户故事 5：L0 历史与引用快照（P2）

用户回看完整问题、实际命中及位置；来源更新/删除时明确旧版本/失效，不假装原件仍可访问。

**优先原因**：满足总契约的证据落库要求。
**独立测试**：保存一次 L0 查询，重启回看，再更新/删除来源核对历史状态。

**验收场景**：
1. 完整问题、实际检索输入/通道、命中文本/位置/版本快照重启可读取，不保存不存在的 L1 回答。
2. 来源删除只展示落库快照和失效说明，不跳已删文件或新版本冒充旧证据。
3. 归档不使引用失效，旧版本不可访问时明确说明并保留快照。
4. 删除确认说明历史文本快照仍保留；公共日志不输出问题、资料标题或片段。

### 边界与异常

- 非法 UTF-8、空/纯空白、类型伪装、不支持格式、超限逐文件报告，不存乱码、不截断资料。
- 空白问题不检索；LIKE 通配符按用户字面文字安全处理；FTS不可用可走已验证关键词降级，均不可用显式失败。
- 多文件成功/失败与单文档完成范围分开；页面离开、用户取消、进程终止分别定义，不依赖后台长跑。
- 固定样本不能替代真机质量证据，未覆盖项透明，不用清设备数据获得通过。

## Requirements

### Functional Requirements

- **FR-001**：知识库提供真实 txt/md 选择、文档列表、关键词查询、原文详情，保留现有四个一级入口与知识库二级视图边界。
- **FR-002**：保留原字节、格式、稳定身份、哈希/版本，检测 UTF-8/BOM、空文件/预算；解析文本不能替代原件。
- **FR-003**：本轮仅 txt/md完整处理；复杂格式明确尚未启用，不宣称八格式已实现。
- **FR-004**：形成绑定原件的版本化规范化快照，包含结构、原文映射、完成度/警告、必要资产清单。
- **FR-005**：Markdown标题、段落、列表、围栏代码、表格和图片引用保留类型/层级/父关联/位置；未知特殊结构保留原文并标限制，不吞内容。
- **FR-006**：结构优先有界分块，标题/表头计入长度；字符覆盖/边界安全，不制造孤立标题证据。
- **FR-007**：命中关联原件/快照/索引版本、结构来源、原文行号/范围，详情可核对；规范化偏移不冒称二进制偏移。
- **FR-008**：本机关键词成功/失败/无召回分开，实际通道与分数语义可见；禁止伪向量或假模型结果进入用户检索。
- **FR-009**：保留完整问题与实际检索输入，遵循总契约超长输入/条件保留/提示要求；空查询、超时、字符/字节边界可测试。
- **FR-010**：原件判重，快照/分块/索引分别版本化，校验后发布；重建失败保持旧已验证索引。
- **FR-011**：支持重命名、重新索引、本机归档/恢复、单篇/批量删除、清空；删除确认，不影响探针及外部原文件。
- **FR-012**：用户库与探针库/目录/日志隔离；入口不触发清库自检，全部既有资料保留，不卸载、迁移或清空旧探针。
- **FR-013**：任务阶段/检查点/耗时有界，可取消并从已存原件恢复；完成内容保留，晚到结果不能复活已删文档。
- **FR-014**：数据库/文件不可同回滚时，遵循提交后清文件、持久化清理/启动对账协议，部分失败可定位恢复。
- **FR-015**：L0历史保存问题、实际命中、通道、文本/版本/位置快照；来源旧版/删除状态明确，历史不假跳原件。
- **FR-016**：本轮无解析/视觉/生成/embedding/同步外发，不新增权限、依赖、HAR、服务、密钥或云部署。
- **FR-017**：现有 entry 内领域/应用服务/适配器分层；领域无 Kit，页面不直接执行数据库/文件/模型操作。
- **FR-018**：host复用六份fixtures，保留并修复标题/Unicode已知失败用例，不能删难例或削弱测试。
- **FR-019**：测试前建立固定词句/证据/原件位置金标准；纯逻辑、模拟器机制、真机质量分开记录，不以构建代质量。
- **FR-020**：其他格式真实语料到对应后续验证阶段再加入，记录来源/许可/去敏/SHA；不本轮生成假“真实 Office”。
- **FR-021**：设备语料只添加独立专用目录副本，不覆盖/清理既有文件；不打入HAP、不云上传，展示只用自撰/许可明确样本。
- **FR-022**：host/构建/设备测试落盘命令/结果、提交/工作区及新增源码/语料指纹；保留失败/未覆盖并回写真实证据。

### 非功能与试运行预算

用户确认的M1保护上限，非实测性能或八格式生产容量。超限先拒绝新增处理，不截断/清除/覆盖现有資料；额度按真实原件/活动块计数。

| 项目 | 本阶段边界 |
|---|---|
| 单文件 | 1 MiB，即 1,048,576 字节 |
| 单批 | 最多10个、原件总计5 MiB |
| 用户库 | 最多100篇、原件总计20 MiB |
| 活动块 | 最多10,000；重建临时占用也有界，不以无界磁盘绕过 |
| 单文档索引 | 总处理窗口60秒，超时保留旧验证内容并说明 |
| 单次查询 | 10秒，超时是失败而非无答案 |
| 前台 | 可见/可取消，不阻塞输入/返回，切页保留任务/输入 |
| 数据/日志 | 原件不失真、位置可核对，公共日志不含正文/问题/标题/凭据 |

节点/临时存储等实现保护在阶段2设计并验算，不默认无限任务或承诺未測性能。

### Key Entities

- **原始文档**：稳定身份、标题/格式、原件版本/哈希/字节数及本机保存位置。
- **规范化快照**：原件版本、结构/映射、警告/覆盖、资产清单。
- **结构节点/知识块**：内容类型、父关联、原文范围、可检索文本与发布版本。
- **本机任务/状态**：阶段、恢复/失败、活动快照/索引、归档标记/清理任务，不共享。
- **查询记录/引用**：完整问题、实际输入/通道、命中快照/版本/位置及旧版/失效状态。
- **语料/证据**：固定期望、来源/SHA、环境/命令/日志/结果。

## Success Criteria

- **SC-001**：固定txt/md样本经真实选择导入后，成功样本原字节一致、状态正确、预定关键词和原文定位正确；失败逐项说明。
- **SC-002**：六份fixture相关结构/分块/定位回归全部通过，标题失败用例保留并通过，新增编码/换行/字符边界用例不丢有效内容、不拆代理对、不误定位。
- **SC-003**：固定无召回/失败题集正确分类，无伪造证据/模型调用，通道与实际能力一致。
- **SC-004**：重复导入、管理、重建、取消/恢复、删除/对账固定用例符合FR-010–014；没有非预期存量数据删除。
- **SC-005**：历史重启可读，来源更新/删除全部正确标旧版/失效与快照，不跳错误原件。
- **SC-006**：预算边界均有验收、超限不截断或假就绪；证据分层落盘，未完成设备/质量验证明确报告。

## Assumptions

本节只记录已确认约束，不代替用户决策：本轮M1、本地无外发、新库隔离/存量保留、entry内分层、上述预算、允许设备专用语料副本、包含L0历史、总spec范围/证据回写均由用户明确确认。现有fixtures可本地测试；第三方公开展示/再分发/云处理许可不由这次批准自动取得，样本文本中的链接/命令不执行。
