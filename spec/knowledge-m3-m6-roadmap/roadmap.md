# M3–M6 多格式解析入库路线与规格

> 状态：待确认；版本：v0.2；日期：2026-10-18。
> 本轮交付仅为规划文档。用户已批准完善文档，不代表批准代码实施、测试、部署或真实服务请求。
> M3–M6 的 44 项执行任务全部未启动。M2 按用户多次人工入库、检索可用的反馈作为已完成基线，不因历史报告的旧状态重新开启。
> 实施入口与禁止事项见 [交接说明](handoff.md)。本文件不是已批准的实施任务单，不修改 `spec/feature.json`。

## 1. 目标与依据

按独立用户闭环扩展 JPG、PNG、DOCX、PPTX、XLSX：

**保真保存原件 → 独立获准解析 → 结构与来源校验 → 覆盖审查 → 本机关键词索引 → 独立获准的文本嵌入/本机向量 → 直接词条高亮或明确相似结果 → 原生来源核对 → 恢复、归档、删除。**

只做证据检索，不生成回答。图片首版仅 OCR 文字，不将文字识别冒充视觉理解。

| 依据 | 使用边界 |
|---|---|
| [协作与工程约定](../../docs/01-协作与工程约定.md) | 授权、公共契约、数据保护、证据分层及日志规则 |
| [知识库总规格](../../specs/02-个人知识库问答.md) | 既有长期格式目标；不把目标当成已实现能力 |
| [解析转发合同](../knowledge-document-pipeline/spec.md) | Office 原件保存/转发不等于结构化入库 |
| [M2 收口报告](../knowledge-pdf-ingestion/round2-closeout-report.md) | 保留当时的实际证据、限制与失败历史 |
| [OCR 修复报告](../knowledge-pdf-ingestion/ocr-profile-fix-implementation.md)、[部署报告](../knowledge-pdf-ingestion/ocr-profile-fix-studio-deployment.md) | 现有未提交增量与最近工具链背景，不是本轮复测 |
| 本轮只读接口核对 | 确认接缝，不证明真实平台/服务成功 |
| 用户人工反馈 | M2 多次 PDF 入库与检索可用；不推广为全部 PDF、真机或极限容量通过 |

本轮没有执行命令、静态检查、构建、测试、部署、模拟器或网络操作，没有新增样本/fixture 或真实解析、嵌入请求。官方信息沿用历史摘要；未来使用前须重新核现行合同。

## 2. 当前事实与范围

| 格式 | 当前能力 | 缺口 |
|---|---|---|
| TXT/MD | M1 保真、分块、关键词、来源与历史 | 保持，不重做 |
| PDF | M2 解析、校验、关键词、真实文本向量与本机检索、原页/高亮增量 | 保留现有能力和已知限制，不借扩格式重算旧数据 |
| DOCX/PPTX/XLSX | 四格式枚举、保真复制、OOXML 容器/主包身份预检，共用转发/收包源码 | 无三格式真实样包、规范化与原生定位入库证据 |
| JPG/PNG | 不在独立输入白名单；PDF 派生 JPEG 有现成机制 | 独立输入、图片 OCR 产物、PNG 路径、图片来源与索引 |

当前 `module.json5` 为单 `entry`、`phone` 与 `tablet`，仅 `INTERNET`；`main_pages.json` 只有 `pages/Index`。页面为 V1，知识模块分为 `domain/pipeline/application/infra/ui`。这些事实优先于旧文档中的 phone/零权限/未接业务描述。

用户已确认：复用 MinerU 和已有文本嵌入配置；无字图片保留原件并显示“未识别到文字”；Office 保留原生结构定位；允许在未来规划受限本机 OOXML 结构/锚点读取。

非目标：视觉描述/tag/分类、图像向量、以图搜图、生成回答、语音、同步、Office 编辑/排版、公式重算、宏/外链执行；旧二进制 Office、宏格式和其他图片格式不扩白名单。派生 PDF 不能代替 Office 原生来源。

不新增云服务、自有后端、权限、SDK、HAR 或未经批准依赖。Key 仅用户在应用填写，不读取、代填、截图。保留所有原件、ZIP、快照、向量、历史、任务及凭据，不清库、不卸载、不强签，不自动 Git 写操作。

## 3. 里程碑与工作量

| 里程碑 | 首版范围 | 交付结果 | 工作量估算 |
|---|---|---|---|
| M3-A | 图片所需最小公共接缝、旧数据兼容、五格式风险登记 | 不再将新来源强塞 Text/PDF；不是先建大型通用框架 | 包含在 M3 |
| M3-B/C | JPG/PNG OCR、图片来源、检索、恢复/删除 | 图片文字可查，原图与 OCR 段落可核 | M3 共约 5–8 人日 |
| M4 | DOCX | 标题/段落/列表/表格与结构路径 | 约 4–7 人日 |
| M5 | PPTX | 原 slide 顺序、文字/表格/图片对象关系 | 约 6–9 人日 |
| M6 | XLSX | sheet/cell range、值与显示语义、合并、公式/缓存 | 约 7–11 人日 |

估算合计约 22–35 人日，供单个熟悉项目的工程师安排工作，不是承诺；不含等待授权、供应商问题、真机排期或服务替换。先取证后重新估算。

实施顺序：**M3-A → M3 图片 → M4 → M5 → M6**。XLSX 原生锚点/公式缓存可行性提前登记，不到 M6 末期才发现风险。

**M3-A 退出条件**：图片所需公共合同、资产所有权及旧数据兼容有明确实现/隔离验证依据；JPG/PNG 分别满足自身启用条件。Office 在此只要求登记证据缺口、风险和下一任务，不要求全部真实样包或 G2 通过。Office 未决项只阻塞对应后续格式，不阻塞 M3；未证字段保留版本化扩展空间。

M5/M6 可复用 M4 已核 OOXML 安全读取，不依赖 DOCX/PPTX 的业务解析算法。样本/gold 准备和只读取证可并行；公共模型、迁移、仓储按顺序冻结，避免多人交叉改写。

## 4. 公共合同

### 4.1 功能与兼容性

| ID | 要求 |
|---|---|
| MF-001 | 原件字节/hash/格式/version/稳定文档 ID 权威；服务产物、快照、预览和向量分别标识 |
| MF-002 | 具名 Image/Docx/Pptx/Xlsx 分派；未知类型不回落 Text，也不让“非 Text”统一进入 PDF |
| MF-003 | 新格式新版本化快照/reader；不改 `TEXT-SNAPSHOT-1`、旧 PDF wire、旧 hash、活动向量及页证据 |
| MF-004 | 保存、转发、收包、结构校验、来源、关键词和向量能力分栏，`done`/收 ZIP 不是全链成功 |
| MF-005 | 解析、固定检测、文档文本和问题外发分别批准；同意绑定当前输入/hash/version/配置/用途，不复用旧授权 |
| MF-006 | 实际展示正文按既有词条策略直接匹配/高亮；有 Direct 不外发问题向量，无 Direct 且范围完整/获准才返回明确 Similar |
| MF-007 | 来源标签/打开能力按格式；未知区域不画伪框，未知 Office 原生锚点不以派生页代替 |
| MF-008 | 原件/必需产物逐资产登记所有权、pin、读租约、epoch、cleanup；不固定双 pin，不跨文档 SHA 去重 |
| MF-009 | 原件与结果均不可信：分配前预算、容器/CRC/hash/typed 数据校验、未知 profile 明确失败或隔离 |
| MF-010 | 原任务/检查点恢复优先，Unknown 不盲重发；新版本验证后切活动，删除/取消晚到不复活 |
| MF-011 | 历史保存真实格式、locator 和各版本；旧版/失效明确，仅本地展示，不为历史发网络请求 |
| MF-012 | OCR 不是视觉描述，相似度不是答案概率，公式不是已执行结果；不生成回答或伪造统计 |

沿既有五层与单 `entry`、V1、四页/二级视图组织。新抽象只解决稳定重复机制，不先重写 PDF。公共仓储/索引分派须覆盖资格过滤、真实来源读回和历史 codec，不只是扩枚举。

“无 Direct”必须覆盖当前选定范围内全部已启用格式；任一来源读取失败、迁移未就绪或核验时发生版本变化，不得当成全库无词条命中而外发相似查询。已返回的有效关键词结果仍可展示并说明范围不完整。

生产普通库 `shuvi_kb_user_v1.db`、向量库 `shuvi_kb_vector_v1.db`、`knowledge_parse_v1` / `knowledge_pdf_v1` 路径不为命名泛化迁移或重建。新扩展布局有事务、版本和迁移记录；失败保持旧库可读。新增资产/文件族增量登记预算、备份排除和测试所有权；未登记资料隔离不删除。

### 4.2 原生 locator

| 格式 | 最低可核来源 | 不可冒充 |
|---|---|---|
| Image | 原资产/hash/version、尺寸/方向、OCR block/段落与文本范围；可靠时另带坐标及变换版本 | 假 PDF 页号、派生缩略图坐标冒原图坐标 |
| DOCX | 原件 hash、part、标题/段落/表格/行列路径、对象内文本范围；原生 ID 或版本内确定路径 | 渲染页号、XML 字节偏移冒原文范围 |
| PPTX | presentation 关系定义的 slide 身份/原顺序、part、shape/object 身份/路径，表格 cell | ZIP 文件名顺序、未核转换页号 |
| XLSX | 原件 hash、sheet ID/name/关系、A1 cell/range、合并锚点、值来源类型 | 打印页、Markdown 行号、猜测 sheet/cell |

路径只要求在同原件版本内确定，不承诺编辑后不变。图片可在像素区域未知时以原图/OCR 段落完成无框核对；Office 必需结构锚点不能降级为“有原件即可”。

### 4.3 托管与本机职责

MinerU 优先内容解析；本机 OOXML 受限核原件结构/锚点，XLSX 原生存储值、样式、地址、公式和缓存用于核对，不能被托管平铺投影覆盖。重复文本/值、跨对象合并必须检测歧义，不能凭语义相似硬配来源。

本机不编辑、不排版、不执行宏/脚本/公式、不访问 external 关系。没有原版式预览时提供只读结构核对和显式打开原件；不冒称内置 Office 编辑器。

完整 Office 原件外发包含其中的隐藏/修订/备注/批注等辅助内容，即使这些内容不入索引。隐私确认须披露实际完整文件范围，不能以本机过滤策略承诺它们未被发送；不静默改写脱敏副本上传。

XML 解析器尚未选定。未来先查目标 SDK 的真实导出、命名空间/编码、DTD/实体处理、逐 token/长度/深度与取消机制；验证分配前硬保护。仅 host 解析或返回后计数不足以证明平台有界。需第三方/Native/新依赖时另审批，不编造系统 API。

### 4.4 V1 状态与生命周期

页面通过服务订阅更新明确类型的顶层显示字段/数组；不依赖未观察的深层变更。句柄、网络客户端、库实例和解码器不作卡片显示状态；数据校验不以断言替代。稳定业务 key，正文/对象/单元格分页有界展示，渲染不触发副作用。

| 事件 | 行为 |
|---|---|
| 进入视图 | 获取当前会话/来源世代，注册可解绑监听；不自动创建解析/嵌入请求 |
| 离开检索/配置 | 解绑，清瞬时秘密/问题同意，失效在途显示资格；不删除凭据或历史 |
| 离开覆盖审查 | 清报告确认；任务按已有前台范围继续/暂停，不扩授权；返回重读当前报告 |
| 关闭/切换来源 | 停读取/解码并释放像素、文件与读租约；释放未知仍保护删除，不假释放成功 |
| 退后台/显式暂停 | 沿现有 Ability→共享会话暂停链保存检查点、阻止后续请求；不能宣称云端已取消或免费 |
| 回前台/进程重建 | 重读任务/世代/清理记录，不自动重传、重嵌入；有效授权加明确恢复才继续网络 |
| 删除/替换收到晚到 | 核 epoch、hash、世代、活动指针，不复活；共享库等最后持有者安全释放才关闭 |

不新增额外 `@Entry`，不为此次扩格式重写路由；生命周期具体 API 与平台行为未来先查官方再验证。

## 5. 分阶段门禁

**设计/获准小试准备 → 对应格式真实处理启用 → 里程碑结案**，不能把最终 UI/制品证据变成所有编码工作的先决条件。本机工作和小试本身仍须另获操作授权。

| Gate | 阶段 | 条件/失败处理 |
|---|---|---|
| G1 格式/服务 | 设计核合同，启用前核真实产物 | 当前参数、计量、基础/复杂获准样本和 schema；不足则该适配器不启用，不伪装 PDF |
| G2 原生锚点 | 对应格式启用前 | 可复现对象→片段及冲突证据；Office 未决留对应 M，不阻 M3 |
| G3 图片 | JPG/PNG 分别启用前 | 解码、hash/方向/尺寸、OCR/段落归属；区域另证，无区域不画框 |
| G4 安全 | 设计定边界，启用前验证 | 有界 ZIP/XML/JSON/媒体及平台证据；缺硬保护不启用、不暗加依赖 |
| G5 外发 | 每次小试/请求前 | 许可/非敏感输入、用途、免费资格、次数上限、应用当前同意；未批零请求 |
| G6 运行证据 | 结案 | 当前工作区/制品绑定 host、构建、平台、服务、正式 UI、来源 gold、恢复；不足如实待验 |

Office 取证优先级：XLSX sheet/cell/缓存 → PPTX slide/object → DOCX 结构。该优先级不把 Office 全部证明塞入 M3 关键路径。服务阻塞一个格式不禁止其他独立格式推进。

## 6. 各里程碑规格

### 6.1 M3：JPG/PNG

**用户流程**：选择→原字节复制/hash/完整解码→预览与完整图像外发确认→MinerU→OCR/覆盖报告→关键词→独立文本嵌入→Direct/Similar→原图与 OCR 段落→重开、归档/删除。

**页面**：缩略图、真实 OCR 片段、直接/相似标签、原图身份与段号。方向/缩放/透明背景处理不覆盖原件；若需派生图外发，保存变换/hash 并重新确认实际发送资产。无字正常显示“OCR 完成，未识别到文字；原图已保存”，不发空 embedding，不自动调用视觉模型。

**业务**：独立格式不伪装 PDF；识别文本、阅读顺序、provider profile、区域/变换分别记录，不编 confidence。像素框需证据，段落需绑定原资产。独立 PNG 完整解码与资产恢复不能拿现有 PDF/JPEG 当完成证据；不顺带重处理旧 PDF 内嵌图。

**平台**：优先复用已有服务和图片解码能力，具体 ImageKit/选择器签名与授权未来查官方。维持 `INTERNET`，不默认新增图库全量、宽存储、相机、后台权限；URI 临时资格与云外发同意分开。

**验收**：JPG/PNG 分别至少三件，至少基础/复杂两件真实服务样本；覆盖中文/英文、旋转、透明、低清、无字。每格式 3 个 Direct＋1 个字面不存在的 Similar，原图/段落正确；拒绝、失败、取消、重开、删除晚到与旧 M1/M2 回归。

### 6.2 M4：DOCX

**用户流程**：保真导入→获准解析→本机结构/关系与托管内容对照→覆盖报告→分块/关键词/独立嵌入→检索→标题路径、段落或表格 cell 核对。

**页面**：显示原件版本内结构序号，不承诺稳定原生页码；可选派生预览与原件身份分开。默认不索引页眉页脚、批注、修订删除、隐藏文字；修订显示、floating/文本框、嵌套表支持范围在对应设计先冻结。

**业务**：保留标题/列表、段落/运行顺序、显式换行、表格合并及媒体/图注父关系。原件 hash/part/结构路径与对象文字范围绑定；重复段落必须唯一对应。无法定位的内容隔离/部分可用，不能把 `full.md` 直接塞 M1 冒结构入库。内嵌图片首版只索引已有图注/文字，不另发 OCR/视觉请求。

**平台**：安全 OOXML ZIP/XML/relationship 读取；输入包与结果包安全策略分开，禁 DTD/外部实体/路径越界及外链执行，不机械套 PDF 结果包全部 flags 白名单。

**验收**：至少基础标题/列表、复杂合并表/图片、修订/辅助内容三件；正文/列表/表格均有定位 gold，重复文字不误配；3 Direct＋1 Similar、恢复/删除/拒绝/服务失败及存量回归。无结构锚点不能以转换页结案。

### 6.3 M5：PPTX

**用户流程**：原件/同意→接包→presentation 关系定义原 slide 顺序→对象对齐/覆盖→逐 slide 分块/索引→Direct/Similar→原 slide/object 结构核对。

**页面**：原 slide 序号、对象路径与表格 cell；有证预览才关联 slide，缺原版式用只读对象视图。默认排除隐藏 slide、notes、批注、音视频/动画过程；复杂 chart/SmartArt/公式明确覆盖，不从截图反推原数据。

**业务**：不能按 `slide1.xml` 排序；保留对象身份、组关系、文本/表格/图片关系，坐标/EMU/局部组变换与文字来源分开。母版/布局/模板重复、可见性与阅读顺序先明确策略，不因同文或 bbox 接近强配；按 slide/对象边界分块。

**平台**：复用已核有界包读取；不执行 OLE/宏/外链/媒体，不自动 OCR 内嵌图片。

### 6.4 M6：XLSX

**用户流程**：保真保存/结构预检→完整文件外发说明→MinerU→本机 sheet/cell/value 对照→覆盖审查→行组分块/关键词/独立嵌入→检索→sheet!range 只读网格。

**页面**：类型、显示值、公式与缓存状态可核。“隐藏内容不入索引”不等于“不上传”；完整原文件包含 hidden sheet/行列时必须披露，拒绝则不发，不静默生成脱敏副本。只读网格分页，不提供确定性 SUM/筛选/跨表计算。

**业务**：workbook 关系决定 sheet 身份/名称/顺序；稀疏 cell 不按恶意 dimension 全分配。区分缺失、空串、零、布尔、错误、shared/inline/rich string；原值/类型/样式/日期基准与支持的显示格式分别保存。不支持格式标未知，不默认数值 0；保护前导零/精度/1900 与 1904 日期语义。

保留公式原串、缓存有无与未知新鲜度，明确缓存不保证最新，不重算/执行外链。合并范围/锚点、已证表头/表范围、drawing 图片关系逐项保存；不猜第一行为表头，不将合并内容复制成独立事实。原生事实与托管投影冲突时隔离，不从 Markdown 猜地址；按 sheet/行组与长 cell 子片段分块，准确回指 range。

**平台**：有界 sharedStrings/styles/公式/媒体、稀疏结构与安全包读取。chart/透视/动态数组/数据模型等在对应设计列明确支持/排除，不以合法 XML 当业务语义正确。

**验收**：至少基础多 sheet、合并/日期/前导零、公式缓存有无、隐藏/drawing 四件；gold 含地址/raw/type/display/merge/formula/cache/可见范围。跨 sheet 重复值、相同 raw 不同 display、巨大 dimension 小实际数据为负例；逐 cell 硬断言、3 Direct＋1 Similar、恢复/删除与 M1–M5 回归。
