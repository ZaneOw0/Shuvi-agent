# 知识库手机端流程与运行时修复

状态：已实现待验收；2026-10-22，基线 `dev/rag` / `9ab89b4`。

## 用户流程

知识库默认用于搜索；「我的资料」进入文件列表，「＋ 导入文件」选择 TXT / Markdown、PDF、图片或 DOCX。文本本机解析并自动入库；其他格式先保存原件，打开单份文件后确认完整文件发送至 MinerU 及免费资格，完成解析后自动消费 ParsedDocument、发布正文/OCR。收到结果但尚未入库时可在此文件详情重试本机入库，不再次上传。

本次用户明确免除旧文件迁移与兼容验收，不新增历史迁移，也不自动清除设备既有资料。新导入正确解析与入库为本轮标准。底层旧仓储和受管资产保护保留，旧库统计不再参与新统一检索范围捕获。

## 页面事项

- 首页只展示搜索、我的资料和折叠历史；发起搜索后展示内容匹配、相关资料和实际需要的分页。
- 列表每份文件只显示一条文件名与状态，支持文件名筛选和查看归档；原件与统一内容按 source ID 合并显示。
- 内容、图片、解析状态、归档和删除放在单份详情。ZIP、hash、覆盖率、重建和清理不平铺在列表；技术信息收进「处理详情」。
- 导入选项纵向排列，避免手机窄屏挤压。知识库不展示助手的演示场景横幅。
- 外发接收方、完整文件范围、可能留存和免费资格仍明确说明，相关确认合成一次操作；语义搜索以本次实际问题、接收方与可能费用一次确认，继续保留后端持久授权校验。
- 搜索后收起键盘；从文件列表进入详情及返回时回到顶部。删除仍单独确认。

## 业务与 Agent 事项

### Promise / 数据库对象身份

服务、仓储、导入适配器和原生资源使用普通引用传递。禁止用 `@Prop` 深拷贝含 Promise、RdbStore 的服务对象；父页面不以 `@State` 代理这些资源。加载中不挂载子资料页，服务就绪后创建，页面仅观察 DTO 和布尔状态，并用服务监听更新显示。

### 空库摘要

原生 Md.update 对空 DataBlob 报 `update failed`，空范围导致 Direct 与 Tags 同时失败。`KnowledgePlatformIdentity` 抽到可独立验证的实现；空输入跳过 update，始终调用 digest，得到标准 SHA-256 空输入摘要；非空输入保持原算法与字节。错误不伪装成无结果；默认给可理解提示，需要时展开原因。

不新增依赖、权限、云服务、SDK 或数据库布局；保留 ParsedDocument 契约、费用与任务重入约束。未知请求不自动重新申请。

## 验收方式

- 正常：新 TXT / PDF / JPG / DOCX 通过正式 UI 导入；统一内容入库后检索独有短语，打开对应来源；空库无结果且不报范围错误。
- 异常：入库失败留在所选文件，不能误跳到上一次已打开的资料；未知/失败请求不自动重传；错误提示与重试可达。
- 拒绝：系统选择器取消、外发确认取消及不启用视觉/嵌入，不产生对应请求。
- 模型失败：语义失败保本机匹配，解析服务失败保原件和可理解原因。

## 2026-10-22 补充：图片真实服务与语义诊断

- 语义 review 在任何外发前分别校验启用、费用、暂停、工程基线、配置绑定、完整范围、统一空间和合格目标，返回具体可操作原因；失败时清除上一次已撤销的确认，不能显示过期可发送按钮。
- 视觉服务明确 HTTP 401/403 记为 Failed，展示独立凭据/模型权限操作提示；仍需用户明确重试，不自动重发。网络中断、未知响应继续保 Unknown 约束，不重写旧账本。
- 视觉与语料嵌入各自拥有一个运行器。任一队列空闲时新任务立即启动，不因另一队列的长文档等待；暂停、停止和 drain 同时追踪两条队列。
- 持久化准入写入 InFlight 之后、实际 launch 之前前后台发生变化，当前进程能够证明未调用 launch 的尝试记 NotSent，暂停作业可恢复。已经调用 launch 的失败继续按已有未知结果策略处理，不根据此修复自动翻写历史 Unknown。
- 图像召回使用有效描述/tag 的文本向量；原图作为来源展示，不新增图像像素多模态嵌入服务。真实服务证据见 [图片与语义验收](vision-semantic-verification.md)。
