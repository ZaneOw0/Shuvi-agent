## Overview

复用已经完成的 PDF 解析、安全入库、343 块真实向量索引与恢复链路，只补齐当前验收所需的原页依据对齐、直接/相似结果区分和展示片段词条高亮。用户明确同意复用已有真实解析结果及向量，不重发 MinerU、不重新向量化，不把原页区块叠加高亮、大模型生成回答或完整 16 题语义质量评分作为本次交付门槛。

当前增量适用以下三个用户故事和 FR-033–FR-041、SC-007–SC-010。后文 ROUND2 之前的需求与历史基线保留；若旧验收门槛与本轮收紧目标不同，以本节为本轮交付范围，而非将旧未验项改成通过。既有安全、凭据隔离、预算、存量保护和真实证据纪律继续生效。

### 用户已确认的范围

- 高亮是**检索结果片段内的命中词条高亮**，不是打开原 PDF 后的区域叠加高亮。
- “本地向量化”沿用既有云嵌入、本机保存向量与 KNN 检索；不要求本机模型执行 embedding。
- 历史真实上传解析证据与本轮既有结果衔接验收，不另建 MinerU 任务，不重复上传或重嵌入 343 块。
- 词条按展示片段逐字匹配，忽略英文字母大小写；多个空白分隔词条任一命中即直接命中，并只高亮实际命中的部分。
- 当前检索范围有直接命中时，优先只展示直接结果；确实没有直接命中时，才在独立获准的语义查询下返回相似片段，并显式标“相似结果”。仅标题前缀命中不能冒充展示片段直接命中；相似片段不伪造词条高亮。
- 沿用现有功能目录，只增量更新当前 spec/plan/tasks；旧报告、16 题冻结 V1 与其摘要保留，不按查询输出修改。

## User Scenarios & Testing

### 当前 User Story C1 — 先核对依据，再显示真实原页（P1）

用户查看命中文字块时，卡片直接显示真正原 PDF 的物理页序；如块跨多个原页，显示已核对的页集合。用户不必先点击原件才能知道来源页。

**Why this priority**：确保页面上的“原页”不是未经验证的服务页号换算，便于快速核对依据。

**Independent Test**：原件与既有解析内容逐页/节点只读对照，不调用云服务；卡片页集合与独立原页参照逐项一致。

**Acceptance Scenarios**：
1. 当前原件/ZIP/快照/内容世代身份均匹配时，具备独立内容对应证据的文字块显示“原 PDF 第 n/30 页”或多页集合。
2. 存在跨页或未核片段时，不把首个解析框所属页冒充整块唯一原页；逐项保留已核页及明确“页码待核对”部分。
3. 页映射缺证据、冲突或原件/快照更改时，不显示伪准确原页；旧索引/向量保留，卡片明确未核状态。
4. 当前验收选取的直接和相似结果，都具备可核对的原页标注；准确区域坐标不作为该项通过条件。

### 当前 User Story C2 — 输入词条，直接命中并高亮（P1）

用户输入词条后，本机查找展示片段中确实包含词条的结果，并突出显示这些词条。

**Independent Test**：使用已入库 PDF 中独立核对过的至少三个词条离线查询，核验命中片段、实际高亮字符与原页；不调用 embedding。

**Acceptance Scenarios**：
1. 忽略英文字母大小写的逐字词条匹配，实际命中部分在片段内高亮；展示内容保持原片段，不修改原文。
2. 多个空白分隔词条任一命中可返回，且只标出真正匹配的词条；无词条命中的标题前缀不能成为直接片段结果。
3. 当前可见检索范围内存在直接命中时，优先只展示直接结果，不为该次自动发送问题向量请求。
4. 输入框后来修改时，已有结果的高亮仍绑定产生该结果的实际检索输入，不随当前输入框误变；历史展示同样不触发模型请求。

### 当前 User Story C3 — 没有直接命中时返回明确的相似结果（P1）

用户输入片段中不存在的说法，在独立同意语义查询后，系统可返回相关文字块，明确说明它不是词条直接命中。

**Independent Test**：至少一条冻结的无直接词条命中改述，在获准的一次真实问题嵌入后，使用既有本机同空间向量召回相似片段；卡片来源页可核对。

**Acceptance Scenarios**：
1. 实际检索范围内没有直接片段命中，且用户已授权当前问题外发、免费资格有效时，返回真实同空间向量召回结果并标“相似结果”，不伪造命中字符。
2. 未授权/模型或网络不可用时不发请求，提示相似检索未开启或不可用，不将失败当作无结果，也不编造相似片段。
3. 相似结果只代表候选证据，不标事实概率、确定答案或模型生成回答；没有结果时明确空态。
4. 不重发文档块、PDF、ZIP 或图片；词条和问题查询均保留当前文档/活动世代/归档/删除等过滤。

### 历史 User Story 1 — 多提供商嵌入配置与能力发现（P1）

用户在“我的”独立配置硅基流动、百炼、Gemini、OpenAI 的用途隔离 Key，选择/手填模型。保存不联网；硅基列表真实来自当前 Key，百炼地域/接入显式选择，其他未取证网络能力禁用。模型列表不等检测成功或免费余额。该功能为已实施基线，不在本增量扩大提供商。

### 历史 User Story 2 — 显式最小真实嵌入检测（P1）

用户单独确认免费资格后只发送一条固定非敏感短句。校验模型/条数/index/维度/有限值/非零范数；记录当前修订，不调用聊天。ROUND2 目标检测已实际成功，本增量不自动重做。

### 历史 User Story 3 — 既有 ZIP 安全规范化与覆盖审查（P1）

既有结果经过容器、成员、实际字节、CRC、hash、结构/资产校验，生成唯一规范化快照；服务 `_origin.pdf` 不替代真正原件。已核内容可由用户明确确认后部分发布，身份/容器等硬失败不可绕过。空块/未知末页/跨页风险不冒全覆盖。

### 历史 User Story 4 — PDF 入库、关键词与原件核对（P1）

正文/标题、公式、表格、图注参与检索，页眉/页码为元数据，reference/aside 默认排除可显式包含。结构优先分块、保留来源与版本，重建不重新解析。原件预览与证据约束的区域高亮机制已实施；**真实样包区域高亮正确性不再作为本次简化交付门槛，不被改写为已验收**。

### 历史 User Story 5 — 独立云向量化与真实语义召回（P1）

PDF 块/问题各自授权，真实云向量逐项校验、本机读回与同空间 KNN/融合。模型改变不混空间，失败仍可关键词。ROUND2 343 块和独立人工语料已实测；**完整私料 16 题质量评分不再阻塞本次简化闭环**，冻结 gold 不改，未验仍如实保留。

### 历史 User Story 6 — 统一知识库、历史与资产生命周期（P2）

M1 文本与 PDF 统一入口、历史、归档/删除/恢复、跨阶段 pin/租约与清理保护。已有资料/原件/ZIP/历史/凭据不清除；删除后晚到不复活；逻辑删除和物理清理分开。已实施基线继续回归，不在本次追加完整压力或掉电验收。

### Edge Cases

前缀命中而正文不含词条、候选截断掩盖后续直接命中、大小写变换/Unicode导致高亮偏移、重叠命中、输入变化/旧历史、页码冲突/旧版本/未核节点、跨多页块及空段、相似路径未授权/超时/模型漂移、删除/归档/恢复时的过滤一致性均需明确处理。任何未知原页不能通过同页数或语义相似强行补齐。

## Requirements

### 本次新增与收紧要求

- **FR-033**：先将当前原件的独立原页依据与现有解析节点/块的来源链对齐；绑定原件/ZIP/快照/世代身份，依据来自原页内容而不是检索排名。不能将 provider 页号直接当已核原物理页。
- **FR-034**：结果卡片显示已核原 PDF 物理页序或页集合；印刷页码另列可选。未核/冲突/跨页不完整明确说明，验收命中块必须有真实可核原页。
- **FR-035**：按实际展示片段逐字判断直接命中，忽略英文字母大小写；多个空白分隔词条任一命中可返回，并记录实际命中范围。不能由 keyword/vector 通道名称推断直接命中。
- **FR-036**：结果片段内高亮真正命中的字符，范围绑定结果实际输入与片段内容，支持重叠/重复/Unicode边界；不篡改正文，不把原文定位范围或问题丢弃范围混作高亮范围。
- **FR-037**：直接片段命中优先，仅在当前实际范围确无直接命中时进入相似路径；不能先截断标题前缀候选再据此宣称无直接命中。直接查询无需模型调用。
- **FR-038**：相似结果必须由合法同空间向量召回且无片段直接词条匹配，显式标“相似结果”，不假词条高亮、不生成回答、不将距离当正确性概率。
- **FR-039**：无直接命中时仍须问题专用授权/免费确认及当前配置/输入校验后才调用云嵌入；未授权/失败分别提示，不能自动重发或切模型。所有旧请求授权保持已用完状态。
- **FR-040**：复用已有真实解析结果、343块内容与向量，不重新上传/解析/文档嵌入；仅必要的来源对齐/展示元数据增量演进，既有原件/ZIP/向量/历史及来源有效性保持。
- **FR-041**：本轮交付以C1–C3和SC-007–SC-010为准。原PDF区域叠加高亮、生成回答、完整16题私料语义分数、真机/容量/掉电压力不作为门槛；旧未验项不得因此记为通过，冻结V1题集不更改。

- **FR-018**：真实embedding只发送获准PDF文本块和获准问题，默认关闭、独立Key/同意，不自动外发M1。
- **FR-019**：真实向量数量/对应/维度/有限/非零/读回校验，无伪向量兜底。
- **FR-020**：provider/接入/模型可辨版本/维度/预处理/角色/归一化隔离空间，未报告revision如实记录。

- **FR-030**：仅用户确认免费资格，未知/不足停止，不自动付费/切provider。
- **FR-031**：保留既有ZIP和批准样本，不新解析；后续新PDF复用既有M2-A入口，解析同意不替嵌入。
- **FR-032**：总spec/本机证据增量明确阶段和门禁，历史失败修复保留，不自动commit/push。

### 已批准保护预算

均为保护线，非已测生产容量。超限保留原件、ZIP与旧索引，不截断冒全量。

| 对象 | 边界 |
|---|---|
| PDF/结果 | 单PDF20MiB/50原页、ZIP30MiB；本轮复用已有结果 |
| 解包 | 实际展开100MiB/1000成员；单JSON8MiB；图片2000万像素 |
| 结构 | 2万节点/4万cells，单PDF2000块/全部PDF活动1万块 |
| 派生产物 | 总计500MiB，包括暂存/失活待清理；不按ZIP大小代替实际占用 |
| 时间 | 本机阶段120秒、查询总10秒、单向量请求120秒/前台窗口15分钟 |
| 并发/费用 | 一个活动文档向量任务；免费资格用户确认，客户端不保证余额 |
