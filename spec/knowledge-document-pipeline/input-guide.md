# M2 本机 PDF 入口

本机目录：[.cache/m2-input/user-pdf/](../../.cache/m2-input/user-pdf/)。目录不入 Git 或 HAP。已有同名目录/文件不覆盖、不清理。放入文件只是本机准备，不授权 agent 扫描、读取或上传；本轮没有查看其中任何文件。

用户后续可自行放入非敏感、有权测试的 PDF。明确指定文件、许可/来源、允许读取与外发范围后才进入样本取证；目前四格式许可清单为空，没有真实 PDF/Office 或结果包通过记录。

设备导入由用户手动拖入模拟器，在应用「知识库 > 复杂文件解析准备」通过系统选择器选择。现有六份文本副本和两份 M1 资料保留；agent 不再尝试 HDC 写入，也不搬移或清库。

Token 仅用户在「我的 > 解析引擎」密码框自行填写。不要发送到对话、截图、文件名或日志；本轮 agent 不读取或代填。安全存储失败不提供明文替代。全局解析默认关闭，打开开关不替代每文件确认。

逐文件确认包括完整原件和内嵌图发送给固定 MinerU 精准服务、非敏感测试用途、留存/删除/训练/转处理规则仍未知，以及本次免费资格声明。额度未知或出现收费信号停止，不授权付费；普通个人资料不能利用本例外默认外发。

本轮预算：原件20 MiB、批次3件/40 MiB、复杂原件100 MiB；PDF本机Kit核定1–50原页；结果30 MiB/总200 MiB；HTTP120秒、前台查询15分钟/90次。不可用或超限保留已保存原件并阻止，不按前50页截断上传。

收到包仅“结果已接收，待结构校验”，不解压/索引/预览高亮。M2-B 再用用户明确提交的真实产物冻结 schema、结构、图像/表格/原生位置和PDF原页高亮；Office逐格式继续取证。云 done 或保存成功均不能当四格式完整支持。

本机暂停/删除只作用于本轮副本，云任务或数据可能继续保留。未知申请不会自动重提；已取得批次先查询同一身份，未知占用只在真实终态观察后释放。凭据变化需重新确认，缺凭据可能无法复核，界面如实阻塞。
