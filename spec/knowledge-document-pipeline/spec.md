# Feature Specification: M2-A MinerU 安全配置与复杂文件转发

**Created**：2026-10-14
**Status**：需求待审核；尚未修改应用代码或调用解析任务。
**Input**：继续长线 M2；先实现用户填写解析引擎 API 入口（当前 MinerU），搭建 PDF 和后续 Office 的解析转发链路；留本机 PDF 目录由用户补样本，再安排独立联网样本收集。
**总契约**：`specs/02-个人知识库问答.md`，尤其 5.7、6.2、10.1。本执行规格只定义 M2 首段，不取代长期逐格式门槛。

## Overview

本轮交付 MinerU 官方精准服务的安全配置和 PDF/DOCX/PPTX/XLSX 原件转发闭环：用户输入 Token、选择文件、保存保真副本、逐文件确认非敏感测试用途、上传、查询异步任务并下载结果 ZIP。服务任务完成与本机结果接收状态分开；结果标“待结构校验”，不解析未知产物 schema、不进入关键词或向量索引，不宣称四格式完整支持。

M1 现有 txt/md、资料、查询历史和管理功能保持可用。长期顺序保留：四格式实际产物取证 → PDF 结构/原页高亮/检索 → DOCX → PPTX → XLSX → M3 图片理解 → M4 内容同步 → M5 完整验收；语义/L1 另线。用户新确认允许受限非敏感测试外发例外，但普通个人资料仍受未完成隐私门禁阻止。

### 已确认范围与变更

- 首轮转发闭环先行，不要求本轮完成 PDF 索引或预览高亮。PDF 原页预览与区域高亮仍是 M2-B 明确目标，不用抽取文字冒原页。
- 仅 MinerU 官方固定服务与 Token，不接受任意 API 地址或其他引擎。当前优先精准 `vlm`，不用 Markdown-only 轻量服务作结构基线。
- Token 由用户在应用输入；agent 不要求、读取、代填或截图凭据。Asset Store Kit 保存、更新、删除，网络权限仅解析用途；不新增麦克风/宽泛存储权限、第三方依赖或 HAR。
- 云解析默认关闭；每文件外发完整原件（含内嵌图），须用户明确声明非敏感测试用途、确认接收方/未知留存/免费额度。此例外不表示完整隐私条款已通过。
- 允许创建 `.cache/m2-input/user-pdf/` 空本机入口，不入 Git/HAP；用户放文件不等于授权扫描或云上传。后续只读/上传明确选定文件，模拟器文件由用户拖入，不重试之前受拒绝的 HDC 写入。
- 网络公开 PDF 收集作为单独后续工作：先核验逐文件来源/许可与清单，获准后下载，不能生成伪“真实样本”或把仓库许可证泛化到全部二进制文件。目前获许可四格式清单为空，未下载任何样本。

## User Scenarios & Testing

### User Story 1 — MinerU Token 本机安全配置（P1）

用户进入解析引擎设置，选择固定 MinerU 服务，在密码输入框填写 Token并保存/更新/删除。列表只显示“已配置/未配置/安全存储不可用”，不回显 Token。

**Why this priority**：建立用户自配凭据入口，不在安装包、普通数据库、日志或对话中存放密钥。
**Independent Test**：无真实密钥的非秘密测试值验证设置状态、保存/更新/删除及拒绝状态；真实 Token 只由用户自行填写，未执行则明确未覆盖。

**Acceptance Scenarios**：
1. Token 保存成功才显示已配置；存储异常准确失败，不落明文替代物、不假装成功。
2. 更新替换对应解析凭据，删除后新解析不可启动；不影响 M1 原件、历史或其他用途密钥。
3. 退出设置清理输入/临时内存，不在详情、日志、错误、截图或同步回显凭据。
4. 系统锁定或安全存储不可用时明确不可用，不降低保护等级到普通 Preferences/RDB。

### User Story 2 — 保真保存、逐文件同意与受限测试门禁（P1）

用户选择 PDF/DOCX/PPTX/XLSX，应用本地保存原字节并显示真实格式/大小。用户可只保存，也可在已配置Token、开启解析且逐文件确认非敏感测试用途/免费额度后提交。

**Why this priority**：路线上允许联网测试，不等于普通个人文件默认外发；配置网络权限也不等于同意。
**Independent Test**：取消/不开启/未配置/未确认/超限路径不得产生云请求；本地原件保持可核对。无真实样本不伪造导入验证。

**Acceptance Scenarios**：
1. 类型/大小校验及 SHA256 绑定原字节；取消选择无副作用，二进制不走现 txt/md UTF-8 处理。
2. 原件可以仅保存在解析准备区，不显示索引就绪、不污染 M1 文本列表/数据布局。
3. 显示完整文件/内嵌图发送、服务身份、留存/删除等未核验、只用免费额度及不收费授权；逐文件确认记录绑定原件哈希/版本/用途。
4. 没有各项真实同意或无法确认免费额度时不发请求；启用开关不能代替逐文件确认，普通个人资料继续阻止外发。

### User Story 3 — 异步上传、任务查询与 ZIP 接收（P1）

用户提交一个获准测试件后，看到申请上传、上传、等待/转换/解析、结果下载与“已接收，待结构校验”等状态。服务 done 不能称 App 已解析/索引。

**Why this priority**：建立后续 PDF/Office 共用传输任务，不等待或猜每种格式的内层产物字段。
**Independent Test**：host 验证真实编排逻辑与可注入网络故障；有获准样本且用户自行配置凭据后才能取得实际服务结果。模拟/公开响应不能当真实解析通过。

**Acceptance Scenarios**：
1. 精准 API 申请上传地址后用本机原字节上传，已取得批次/任务身份持久化，上传完成不重复另行创建任务。
2. 按已核 API 的状态有界查询，显示 waiting-file/pending/converting/running/done/failed 的真实阶段；未知状态为兼容性失败，不猜成功。
3. 下载只消费真实服务给出的可信地址，Token不发送至上传/下载存储主机，不无条件跟重定向。
4. 包接收核对实际大小、传输完成与文件签名/本机哈希等传输完整性；下载中断不能标接收成功。
5. 未取实际样包前不解析内层 JSON、不解压未知成员、不建立索引；ZIP处于受限隔离资产，明示结构/定位尚未验证。

### User Story 4 — 暂停、恢复、错误与测试任务清理（P1）

用户暂停上传/查询/下载，重开后看到已保存原件和任务阶段，按现有服务身份继续查询或下载，不默认重提任务。

**Why this priority**：外部排队和本地60秒文本窗口不同，不能盲重提产生重复额度/收费或丢失任务。
**Independent Test**：故障注入校验响应未知、鉴权/429/超时、地址失效、进程中断、取消/删除迟到结果。真平台恢复只能由实际服务/设备证据确认。

**Acceptance Scenarios**：
1. 保留已有任务ID/原件版本/确认记录；提交响应不确定时显示待核对，不假定供应商幂等或自动重新提交。
2. 单次请求/总查询窗口有界，超过等待窗口为暂停可恢复，不冒称云任务已取消或资料无答案。
3. 页面离开或进程退出不承诺后台长跑；重新打开仅列恢复任务，由用户继续。
4. 原件变化、新确认、关闭解析、取消/删除都隔离迟到结果；删除只清应用本轮解析副本/记录，保留既有M1资料，不清库/卸载；服务侧留存与删除能力未核实，明确不能保证清除。

### User Story 5 — M1 保留与 M2 下一段取证交接（P2）

用户仍能检索已有 txt/md；在解析设置/任务视图能看到四格式“仅转发/产物待验证”，以及 PDF/Office完整支持的后续条件。本机目录存在且说明样本仅由用户明确指定后处理。

**Why this priority**：长线推进不能以新设置或扩展格式白名单破坏现已可用资料与检索。
**Independent Test**：旧六fixtures/golden、原件/历史格式回归、解析任务与M1隔离检查；空目录/说明不意味着真实文件样本已批准。

**Acceptance Scenarios**：
1. M1 用户库/原件/快照/历史保留，现有关键词与返回/页面状态不倒退，不迁移到空库掩盖不兼容。
2. PDF/Office结果不能被当前TextNormalizer拒绝后伪改为TXT或用Markdown样例填充；无法处理标明确阶段限制。
3. 已下载结果与原件/任务绑定，可为下一轮schema/表格/图像/原生位置核验提供去敏取证清单；不把签名地址或Token放到公开清单。
4. 建立本机PDF空目录和使用说明，不扫描其他目录；原件不自动入Git、不打包、不上传。联网收集与真实样本调用单独清单授权。

### Edge Cases

无Token、免费额度未知、拒绝同意/选择取消、类型伪装/加密/损坏或超限、鉴权/429/队列/未知状态、上传地址过期/响应不确定、下载大小/ZIP签名不符、磁盘不足、任务恢复或删除晚到、安全存储不可用均明确区分。测试端口返回不能代替真实网络/Asset Store Kit；无样本或Token时真实服务验收记INCOMPLETE，不削弱校验或编造样包。

## Requirements

### Functional Requirements

- **FR-001**：提供固定MinerU精准服务与Token设置，安全保存/更新/删除，只显示配置状态；不提供任意地址/引擎。
- **FR-002**：安全凭据与解析任务/签名地址、个人数据分域；Token不得进普通持久化、日志、截图、对话、Git或同步，也不得转发给对象存储主机。
- **FR-003**：仅新增解析用途INTERNET与已批准SDK安全存储/设置，无麦克风/宽存储权限/第三方依赖/新HAR/自有后端。
- **FR-004**：选择并保真保存PDF/DOCX/PPTX/XLSX，按格式识别/实际字节/SHA验证；M1仍独立按原预算处理txt/md。
- **FR-005**：原件保存与外发分开，默认不开解析；Token配置、INTERNET、全局开关均不替代逐文件同意。
- **FR-006**：只允许用户明确确认的非敏感测试件使用测试外发例外；未知留存/删除/训练/转处理方如实显示，普通个人资料仍被门禁阻止，例外不能变为已核实隐私结论。
- **FR-007**：同意绑定原件哈希/版本、固定接收方、完整文件/内嵌图范围、用途和免费额度声明；确认未取得或已失效不外发。
- **FR-008**：通过官方已描述的精准申请上传→原字节PUT→自动提交→批次/任务查询→ZIP下载，任务关联稳定业务ID，不重复额外创建解析任务。
- **FR-009**：阶段/失败/进度来自真实服务响应与本地执行；未知状态/schema失败，不以空数据、服务done或HTTP200等同应用就绪。
- **FR-010**：分开服务完成、本机包下载/校验和结构待校验；本轮不解压、适配未知输出schema、不规范化复杂文件或建立索引。
- **FR-011**：上传/结果地址经固定可信来源、传输安全/重定向校验；认证只在对应API主机，地址和服务错误去敏，不能显示完整签名链接/响应体。
- **FR-012**：传输/等待/下载有界，额度/付费规则明确；不盲自动重传或重提收费任务，不能把最高优先级额度说无费用保证。
- **FR-013**：持久化阶段、已取得服务身份、原件版本、失效标记和安全恢复信息；提交结果不确定供用户核对，不假定幂等。
- **FR-014**：暂停/关闭解析只停止后续本地动作，远端可能继续；恢复优先查询已有身份，不自动后台长跑；过期地址行为按真实API能力处理。
- **FR-015**：删除/取消/版本变化隔离迟到结果，安全清理仅应用解析资产；不保证云数据删除，不修改既有M1或外部文件。
- **FR-016**：四格式逐项显示“转发/实际产物未验证”与门禁状态，不把文件接收能力当完整支持；原生定位仍是后续硬门槛。
- **FR-017**：M1原件、ID、快照、活动世代、任务、归档与历史完整保留；不得改wire/schema到不可读或切空库，不启动旧探针自检。
- **FR-018**：host包含设置/同意/预算/任务阶段/错误/取消恢复/迟到与结果隔离逻辑，用可注入假端口但生产真实SDK适配；旧96项和六fixturegolden保留。
- **FR-019**：凭据/网络/文件/页面能力查官方SDK，再构建实际产物；host、构建、模拟器/真机、真实服务分层，未执行不称通过。
- **FR-020**：创建`.cache/m2-input/user-pdf/`空入口与明确说明，不入Git/HAP，不自动扫描；真实样本后续逐文件批准读取/上传，公开抓取单独一轮。
- **FR-021**：本輪不下载未知许可的MinerU示例、不自动取用户PDF、不读取Token或代填；免费API可用是用户声明，实际请求由用户配置和确认文件后执行。
- **FR-022**：M2独立任务/证据写入本目录，增量回写总spec长期路线/测试例外/当前未完成，保留M1失败与人工反馈，不Git提交/推送。

### 试运行预算

用户已确认以下M2保护上限，不是实测性能/生产容量。M1预算保留；普通文本和复杂文件分别计量，复杂件不得无限占用派生存储。

| 参数 | 上限/行为 |
|---|---|
| 单复杂原件 | 20 MiB；PDF最多50原页，无法在上传前可靠核定页数时不得隐式全量上传绕限制，设计阶段明确预检/用户确认且结果核验 |
| 单批 | 最多3件/40 MiB，最多1个云任务活动；超限明确拒绝新增，不截断资料 |
| 复杂原件总量 | 单独计量≤100 MiB，M1原件不挪用/清除 |
| 结果包 | 实际下载≤30 MiB，隔离保存；展开≤100 MiB/1000成员为后续解包门槛，本轮不展开 |
| HTTP | 单请求≤120秒，失败明确分类，不无限自动重试 |
| 云等待 | 每文件一次前台等待窗口≤15分钟，耗尽暂停可查询恢复，不假云取消/自动重提 |
| 本地复杂内容校验/索引 | 后续阶段≤120秒，与云等待分开；本轮不宣称已实现复杂索引 |
| 查询 | 沿用M1 10秒，网络转发不拖延本机查询 |
| 费用 | 仅免费额度，收费/额度不明停止需再批准；服务无可靠费用信号时用户逐件确认当前免费资格，不由agent代承诺免费 |

更细的网络次数、临时/结果总磁盘、Token长度与加密缓存/地址生命周期等设计保护在阶段2明确，不用用户预算之外的默认无限。测试文件大小与免费额度不是样本许可或个人资料外发授权。

### Key Entities

解析引擎配置/安全凭据状态、复杂原件身份/hash/version/format、逐文件测试同意及门禁状态、稳定业务ID/服务批次任务、阶段检查点与本地取消失效、隔离结果包与摘要、四格式能力取证清单/许可记录、测试预算与证据。

## Success Criteria

- **SC-001**：本机安全配置固定用例保存/更新/删除/拒绝正确，凭据不泄露；不可用时不明文降级。
- **SC-002**：未授权/未确认/未配置/额度不明的用例零外发；每个允许请求可绑定真实文件确认记录。
- **SC-003**：编排测试完整覆盖真实API已描述阶段、恢复与错误，有界执行，不重复创建任务；包仅隔离保存，绝不显示“索引就绪”。
- **SC-004**：原件/结果传输大小、哈希及任务关联可核对，超限不截断/删旧资料；无真实样本时真实服务取证明确未完成。
- **SC-005**：M1回归/六fixtures原字节/golden保留，设置页/转发功能不损坏现有两份已导入资料或历史。
- **SC-006**：目录说明、门禁/能力显示与文档一致，真实凭据/服务/模拟器结果分层留档，不猜产物schema或冒称四格式完整支持。

## Assumptions

本节只有用户明确确认的决定：固定MinerU+Token、本轮转发闭环先行、Asset安全存储/INTERNET、非敏感逐件免费测试例外、上述预算、批准的样本空目录、存量保留、长线PDF预览高亮/逐格式顺序。Token和实际样本尚未提供，公开四格式许可清单为空；不假定用户现在已经完成设备配置、外发确认或条款审核。

## Open Questions

本轮产品范围已明确；具体SDK传输/安全存储可用性、页数预检、可信存储接收方、结果保存/恢复和免费资格判定需阶段2官方资料/实际契约设计，不能以未核验默认值消除门禁。复杂产物schema、ZIP结构安全、PDF原页定位、Office原生锚点及真实测试件是M2-B/后续取证责任，不在本轮伪造实现。
