# Shuvi 搜索 MCP 服务

当前手机应用直接调用 Tavily，见 [搜索契约](../../specs/03-联网搜索.md)。本 Node.js 服务保留作协议参考、本机验证与既有 CI 测试，不进入 HAP，也不作为手机搜索的运行前提。

## 1. 运行环境

使用 package.json 要求的 Node 24、锁定的 MCP SDK / Zod 与 TypeScript。仅在需要测试此独立服务时安装依赖；凭据只通过本机环境提供，不入库或日志。

```bash
npm ci
npm test
npm run start:discovery
```

`start:discovery` 验证握手与工具发现，不调用供应商。正常服务 `npm start` 读取本机配置，可使用 `npm run smoke` 进行协议检查；涉及真实搜索的调用须在用户授权范围内执行。

## 2. 边界

服务是独立进程，应用中保留的 MCP 探针与 Runtime 启动检查分别验证连接和装配。固定样例、服务测试和真实供应商结果分别记录。

应用当前搜索授权、Tavily Key、来源、费用和本机记录清空由手机链路管理，参考服务的旧回环转发方式不用于当前产品部署。公网认证、多供应商、网页全文提取和服务端持久化不是此服务已验收能力。

## 3. 验证

`npm test` 构建并运行替身供应商用例；具体运行结果以当次日志为准，不能作为手机网络或实际账单证据。主仓库 CI 继续验证该子项目，见 [CI 说明](../../docs/deployment/持续集成.md)。
