# 11 主对话 Agent 知识库 L2 检索增强

> 状态：已实现待验收。主助手在明确授权下自主调用个人知识库，复用统一 L0/L1 底座。

## 1. 用户流程

1. 启用真实助手，打开「知识库授权」。
2. 确认本机检索与命中片段发送给 DeepSeek，选择是否允许问题文本发送至嵌入服务进行语义查询。
3. 正常提问，模型可直接回答、澄清或调用 `knowledge_search`；开关开启不强制每题检索。
4. 有证据时回答绑定真实引用，无依据时明确说明；点击来源卡片查看原文件。
5. 撤销授权、新建/切换对话、停止或退后台后，旧知识来源与派生上下文不再用于后续请求。

## 2. 页面事项

保留知识库授权开关、语义/仅本机检索选择、进度、引用卡片和可理解错误，不新增独立回答 Key 或发送入口。知识库与搜索可以同时授权，网页来源附加后知识库卡片仍显示。

来源按文件与 generation 合并，保留片段编号；来源打开前检查当前文件版本、归档与删除状态。历史来源展示快照不自动恢复工具授权。

## 3. 业务与 Agent 事项

- `ModelKnowledgeTools` 提供工具定义与允许函数，模型用 `tool_choice=auto` 自主选择。
- `knowledge_search` 经 Registry / Runtime 的参数、授权、预算、派发与结果记录后执行；`KnowledgeAgentSearchAdapter` 访问共享生产知识库，查询会话与页面独立。
- 每轮最多 2 次检索，累计去重后最多 5 条 / 3200 字符证据。知识库模式受 90 秒、单轮 3 次模型请求、会话 10 次授权模型请求及输出限制约束。
- L0 返回真实 Keyword / Literal 引擎与覆盖；允许语义时按 L1 配置与合格空间查询，失败明确降级。两条通道保持来源身份与内容版本。
- 回答输出与引用必须运行时校验，编号须存在于本轮已绑定证据；模型自述来源不能生成未验证卡片。
- 资料变更、取消或授权变化使本轮结果失效，不因模型已经生成部分文本继续外发。

## 4. 记忆、平台与隐私

知识来源、使用来源的回答及派生后续上下文只进入当前授权会话的临时历史，不写持久模型记忆与摘要。UI 可以保存回答与来源快照，恢复时仅展示。

仅本机检索仍会将用户允许的命中片段发送给回答模型；语义查询另有问题文本外发和费用。此开关不授权重新解析原件、图片理解或批量入库。

复用既有权限、数据库、向量库与 Provider；无新增依赖或独立知识库回答会话。端口与分层见 [架构](../docs/architecture/知识库L0-L1-L2链路架构.md)。

## 5. 验收方式

| 路径 | 验收重点 |
|---|---|
| 正常 | 普通常识不强制查库、查旧资料与追问、仅本机/语义选择、引用回看 |
| 异常 | 无命中、部分覆盖、资料变化、取消、后台、切换对话与旧来源隔离 |
| 授权拒绝 | 取消授权、拒绝语义、撤销后不再检索或携带来源 |
| 模型失败 | 非法函数/参数/引用、无依据、超时、次数及证据上限 |
