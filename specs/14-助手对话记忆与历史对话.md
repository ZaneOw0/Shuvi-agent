# 14 助手对话记忆与历史对话

> 状态：已实现待验收。普通对话记忆与界面消息保存在本机，知识库上下文按授权会话隔离。

## 1. 用户流程

正常聊天后可切换页面、退后台或重启，再恢复最近对话。侧边菜单可新建、切换、继续和删除历史对话；新对话不携带旧对话记忆，切换后工具授权需重新开启。

## 2. 页面事项

历史列表展示对话标题，聊天恢复文字、日程结果、语音引用、图片副本和知识库来源展示快照。图片副本缺失显示占位；来源原版本已变化、归档或删除时提示不可打开。

知识库来源按文件合并，保留全部引用编号，默认最多展示 3 个文件，可展开其余。来源段后出现网页来源仍生成知识库卡片并保留网页文本。

## 3. 业务与 Agent 事项

`AssistantMemory` 管理当前对话文本轮次、摘要与待告知结果，由 `AssistantContext` 持有。`AssistantConversations` 串行保存界面消息和模型记忆，切换/新建前排队保存离开状态，删除等待进行中的保存；存储失败时提示仅内存可用。

历史超过 40,000 字符时整理较早内容，保留最近约 16,000 字符原文，摘要不超过 4,000 字符并标记仅供参考。摘要失败按现有规则省略旧轮次；单请求历史另有 120,000 字符上限。

普通助手每轮输入上限 262,144 token、输出 8,192 token、本地预算 100,000 micros；单轮最多 6 次模型请求、6 次工具调用。请求还受会话截止时间约束。本地预算不代表供应商实际扣费保证。

知识库来源、使用来源的回答及派生后续上下文只存在于当前授权会话，不写持久模型记忆或摘要；撤销、换对话或关闭后不再携带。UI 快照仅恢复显示，不成为新一轮模型依据。

## 4. 平台能力与数据

- 加密 RDB `shuvi_assistant_conversations_v1.db` 保存界面消息与模型记忆，列表最多读取 500 条，不上传、不同步。
- 图片以私有目录副本保存，消息仅存校验后的文件名，删除对话时一并删除；原图不自动进入后续模型请求。
- 语音引用指向既有本机录音；删除对话不宣称已清理全部录音或系统日历。
- `ChatExecutionStore` 满 128 条或 800,000 字符时优先淘汰最早已完成执行记录，保留继续对话能力；执行日志不提供对话恢复。

## 5. 验收方式

覆盖跨页/重启恢复、连续多轮、摘要成功与失败、新对话隔离、切回旧对话、删除当前/其他对话、存储失败和图片丢失。权限拒绝、模型失败及取消不能使旧上下文或工具授权串入新对话。

来源卡片即时绑定与历史 JSON 恢复的定向测试见 [补丁验证](../docs/verification/发布前补丁验证.md)；普通记忆与知识库隔离见 [集成回归](../docs/verification/PR26-main合入与RAG三链路回归.md)。设备上长历史自动摘要、完整异常路径与真机待验收。

## 6. 当前限制

摘要会丢失细节；较长历史增加每轮发送成本。当前没有全部清空对话入口，需逐段删除。图片孤儿副本与录音管理限制见 [多模态](13-助手多模态消息.md) 和 [语音](10-普通话语音输入.md)。
