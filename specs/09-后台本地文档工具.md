# 09 后台本地文档工具

> 状态：已实现待验收。主助手在同一模型工具循环中创建、读取和修改文本 / Markdown 文档。

## 1. 用户流程

启用真实助手后，用自然语言请求生成并保存、读取或修改文档。模型通过标准 tool_calls 选择工具，Runtime 返回按 tool_call_id 绑定的真实结果，助手继续回答并展示保存回执。

更新以读取到的期望版本为前提；冲突时保留已有内容。结果未知时先核查，避免自动重复写入。

## 2. 页面事项

复用聊天，不新增文档工具页面或固定命令。启用说明明确正文发送给 DeepSeek、文件公开保存位置与当前会话用途。成功回执展示文件名、版本及真实保存位置。

## 3. 业务与 Agent 事项

工具经 Registry、授权、持久化派发与唯一 Runtime 控制入口执行。操作绑定稳定身份与幂等键，同键异参拒绝；模型文本或 DSML 标记不能作为工具调用执行。

私有不可变版本与操作账本保留核查依据。公开文件写入经暂存、摘要校验、FD 复制、同步、关闭和读回；同名陌生文件或外部改动拒绝覆盖。私有提交后公开写入异常可产生不确定状态，不伪造跨应用原子事务。

## 4. 平台能力与隐私

使用既有 API 26 DocumentViewPicker DOWNLOAD 模式，UTF-8 正文上限 256 KiB，保存到 `Download/com.example.shuvi/<fileName>`。系统返回应用下载目录，模型不能指定任意路径，无新增权限。

文档正文按用户授权外发，旧私有文档不在启动时批量发送。权限、文件打开、取消和结果读回均由现有适配器处理。

## 5. 验收方式

覆盖正常创建/读取/更新、期望版本冲突、同名外部文件、取消、授权拒绝、模型非法参数及写入不确定。具体设备步骤、日志与限制见 [后台工具集成](../docs/integration/agent/后台本地文档工具.md)。完整真实模型自主调用和目标设备异常矩阵待验收。
