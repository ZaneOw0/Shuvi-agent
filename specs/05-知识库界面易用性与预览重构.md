# 05 知识库界面与预览

> 状态：已实现待验收。范围：资料库、详情、解析设置与任务、图片理解及嵌入设置。

## 1. 用户流程

1. 知识库 → 我的资料，按时间、名称、分类或文件名找到资料。
2. 打开详情，预览正文，展开全文、图片或处理状态。
3. 点击图片全屏查看；按页浏览正文、图片与任务。
4. 对未完成任务单独重试，或点击「重试未完成」一次确认费用后批量排队。
5. 归档、删除或释放可清理文件前确认；取消保留资料与任务状态。

## 2. 页面事项

| 区域 | 当前规则 |
|---|---|
| 我的资料 | 每页 8 份，分类文件夹每页 6 个；可筛选、切换排序、查看归档 |
| 正文 | 默认最多 3 段、每段最多 4 行；全文每页 12 段，清理展示用 Markdown/HTML 标记 |
| 图片 | 每页 9 张，Contain 展示；可全屏、上一张、下一张和关闭 |
| 处理状态 | 折叠容器 180 vp，最多 3 个未完成项；展开容器 320 vp，每页 5 项，说明在容器内滚动；页码与翻页按钮在容器外 |
| 解析任务 | 时间/名称排序及分类，每页 6 条；待整理结果每页 3 条；本机副本每页 8 条 |
| 设置 | 统一返回、标题与卡片；高级技术信息折叠，Key 由 API Key 管理入口保存 |

打开新资料或重新展开处理状态回到首页。单项重试和「重试未完成」均保留费用确认；无符合条件任务或操作进行中禁用批量按钮。

## 3. 业务与 Agent 事项

批量操作覆盖当前资料全部分页，但只处理当前 generation / epoch 中 Failed、Unknown、Paused 的既有可重试任务，逐项调用 `queue.retry(id, true)`；Pending / AwaitingConfig 已在队列，调用 `kick()` 启动调度。成功进度保留，Complete、Running、Canceled 不重新排队。一项入队失败后继续其他项，显示成功数与失败数；配置未就绪或处理已暂停时继续等待。

本机首见时间只参与旧资料的 UI 排序，不改变内容身份。多图预览复用受管租约，同页最多 9 张，打开失败或离开页面时释放。归档、删除及清理由已有服务执行。

## 4. 平台能力

复用 ArkUI、Preferences、文件与数据库适配器。无新增权限或依赖。原件、索引、任务与凭据使用现有存储契约。

## 5. 验收方式

| 路径 | 验收重点 |
|---|---|
| 正常 | 分类/筛选/翻页、正文和图片预览、全屏、固定高度任务分页、跨页批量重试 |
| 异常 | 预览缺图、内容读取失败、任务数减少、单项入队失败后继续与真实计数 |
| 授权拒绝 | 取消重试、删除或归档确认不写入、不外发；鉴权错误保留原因 |
| 模型失败 | 失败/未知结果显示、复用成功进度、可能重复计费提示 |

[发布前补丁验证](../docs/verification/发布前补丁验证.md) 记录 6 项分页/批量回归及构建；[界面合并验收](../docs/verification/main界面合并与知识库风格验收.md) 和 [多设备验收](../docs/verification/平板端适配与手机对照验收记录.md) 各自限定其版本与设备范围。固定高度与批量重试的本轮设备验收仍待执行。

## 6. 当前限制

复杂表格、公式与扫描版式的简化预览不承诺原件排版。首见时间不代表旧文件的真实创建时间。最大字体、读屏与真机矩阵待验收。
