## 1. 目标与范围

- 目标：把知识库从「开发联调可用」提升为面向用户的可用界面：资料可查找、可预览、图片可浏览、危险操作有确认、技术信息不直接暴露给用户，三个模型设置页使用一致的头图与排版。
- 范围：`entry` 内知识库 UI 与只读展示层：
  - `knowledge/ui/ParsedDocumentView.ets`（我的资料 / 资料详情）
  - `knowledge/ui/DocumentParseView.ets`（解析引擎：设置 / 解析任务 / 本机副本）
  - `knowledge/ui/VisionSettingsView.ets`（图片理解）
  - `knowledge/ui/EmbeddingSettingsView.ets`（嵌入模型）
  - `knowledge/ui/ImageKnowledgeView.ets`（图片详情）
  - `knowledge/application/ParsedDocumentIngestionService.ets`（同页多图预览租约）
  - `knowledge/pipeline/UnifiedProcessingPresentation.ets`（用户化阶段名称）
  - `components/FeaturePages.ets`（「我的」页入口文案）
- 非目标：不改变知识库存储结构、不改写 ParsedDocument/向量/任务契约、不新增权限、依赖或云服务、不触发新的模型/解析请求、不自动归档或删除用户资料。

## 2. 用户流程

1. 知识库首页 →「我的资料」：默认按最近导入时间倒序显示 8 份一页；可切换「按名称」、打开「分类」文件夹、查看归档、按文件名筛选。
2. 打开单份资料：先看到状态与内容预览；可展开全文、展开图片、查看处理状态与处理说明。
3. 展开「文件中的图片」：自动加载当前页 9 张缩略图（3×3），点击任一图进入全屏；全屏可上一张/下一张/关闭。
4. 归档或删除资料：先弹出确认层，明确说明后果；取消不产生写入。
5. 「我的」→ 解析引擎 / 图片理解 / 嵌入模型：三页使用同一返回按钮、标题层级和卡片间距；解析引擎内可切换设置、解析任务、本机副本。
6. 解析任务与本机副本：按时间或名称排序、分类文件夹、分页；任务默认只显示用户可理解的状态，技术细节折叠在「技术信息（排障用）」中。

## 3. 页面事项

- 我的资料
  - 头部：统一返回圆钮 + 标题「我的资料」+「N 份资料 · 保存在本机」。
  - 导入区：可展开四种资料类型；导入行复用 `FeatureRow`。
  - 工具栏：文件名筛选；第一行等宽排列「最近导入 / 按名称 / 分类」，第二行「查看归档」左对齐、「解析设置」右对齐。
  - 列表：每页 8 份；卡片展示类型图标、标题、状态、分类与时间；更新时间优先使用原件 `savedAt`，没有时间戳的旧资料使用本机首见时间（Preferences `shuvi_knowledge_library_v1`，仅 UI 排序，不进入知识库数据库）。
  - 分类：图片、PDF 文档、Word 文档、文本笔记、表格、演示文稿、其他资料；文件夹卡片双列，每页 6 个；进入文件夹后分页 8 份。
  - 空态、搜索无结果、加载与失败提示均保留可恢复入口。
- 资料详情
  - 状态卡；原件未入库时保留「保存到知识库」或「解析这份文件」，云端解析仍逐份确认。
  - 内容预览：默认最多 3 段、每段最多 4 行；提供「阅读全文（N 段）」；全文每页 12 段，可在标题处收起。展示前清理 Markdown/HTML 标记，保留 LaTeX 文本。
  - 图片：折叠区标题显示总数；展开后 3×3 共 9 张/页，缩略图 `Contain` 不裁切公式；点击打开全屏查看器（计数、上一张、下一张、关闭）。
  - 处理状态：用户化阶段名、进度与失败说明；重试仍保留费用/重复计费提示。
  - 处理说明：只展示用户可理解的信息（云端解析进度、正文提取是否完整、可查看图片数、处理提醒数），不再展示解析 ID、哈希、签名、云端阶段码。
  - 归档、删除、「释放未使用的本机文件」均使用确认层；删除确认按钮保留 `upd-delete-confirm` 自动化 id。
- 解析引擎
  - 统一头部「解析引擎」、副标题「把 PDF、Word 与图片变成可阅读、可搜索的内容」；三段式切换「设置 / 解析任务 / 本机副本」。
  - 设置：服务名称、凭据状态、Token 输入与保存/删除（删除需确认）、云端解析开关、文件入口、折叠的服务能力说明。
  - 解析任务：最近/名称排序、分类文件夹（进行中/需要处理/已完成）、6 条/页；任务卡片展示文件名、时间、大小、用户化阶段、进度和故障说明；不展示任务 ID；技术细节仅在二级折叠中展示。
  - 待整理结果：3 条/页，避免结果列表无限向下；移除任务 ID、SHA256 与资源 id 展示。
  - 本机副本：筛选、最近/名称、分类文件夹（图片/PDF/Word/其他）、8 条/页；删除前弹窗确认。
- 图片理解 / 嵌入模型
  - 与解析引擎相同的返回圆钮、标题字号、副标题与卡片规范。
  - 危险操作（删除 Key、删除描述与标签）均确认；模型来源、检测状态改为中文描述；技术基线说明收进高级区。
- 页面状态：加载中、空态、失败、取消与可恢复重试均保留；长文本、图片与任务列表都不再无限纵向堆叠。

## 4. 业务与 Agent 事项

- 不改变业务对象与持久化契约：`ParsedDocument`、`ParsedDocumentRecord`、`UnifiedProcessingJob`、任务/结果/生命周期接口保持原实现。
- 新增的仅有两项展示层能力：
  1. `ParsedDocumentIngestionService.previewImages(ids)` / `closePreview()`：允许详情页同时持有同页最多 9 个图片预览租约；打开失败或取消时释放已开租约，不改变资产验证与读取规则。
  2. `ParsedDocumentView` 的本地 UI 首见时间（Preferences，键 `shuvi_knowledge_library_v1`），用于「最近导入」排序；不写入知识库数据库，不参与检索与同步。
- 危险操作确认只影响 UI 交互顺序：确认后才调用原有 `archive` / `deleteDocument` / `deleteOriginal` / `retire` / `releaseUnknown` / `changeCredential` 等既有服务方法。
- 用户化文案不改变任务状态与重试语义：暂停、恢复、重试、重新整理仍调用原服务；费用与重复计费提示保留。

## 5. 平台能力与权限

- 所需系统能力：既有 ArkUI 组件、`@kit.ArkData` 的 `preferences`（本机 UI 排序）、既有文件/关系型存储与网络服务适配器。
- 无新增权限、无新增依赖、无新增云服务。
- 数据归属：资料与解析结果仍在本机知识库；Preferences 仅保存文档 id 到首见时间的映射，不含正文、密钥或个人资料内容。
- 输入输出：图片预览仍通过既有 `openPreview` 租约与受管路径；删除/归档等写入仍由既有服务执行。
- 超时、取消、重试、幂等与部分失败：复用原有服务语义；图片预览打开失败时释放已开租约并提示，不把缺失图片当作成功。

## 6. 验收方式

| 路径 | 用例 | 预期结果 |
|---|---|---|
| 正常 | 资料库切换最近/名称、分类文件夹、翻页；详情预览、全文、图片 3×3、全屏上一张/下一张；归档/删除确认后分别执行或取消 | 列表不无限下滚；预览可读；图片翻页与全屏可用；取消不写入 |
| 异常 | 图片预览部分失败、资料读取失败、解析任务失败、删除引用被占用 | 保留原资料与已有进度，显示可理解原因和重试入口；不伪造成功 |

| 模型失败 | 图片描述/嵌入任务未知或失败 | 保留此前成功内容，说明结果待核对与可能重复计费；不把失败内容当作可检索成功 |
