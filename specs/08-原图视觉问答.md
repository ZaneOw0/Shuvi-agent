# 08 独立原图视觉问答

> 状态：后端已实现待验收，独立产品 UI 尚未接入。主聊天图片走 [多模态消息](13-助手多模态消息.md)。

## 1. 用户流程

选择一张 JPEG / PNG / WebP，后端读取并去元数据重编码，用户明确同意图片与本次问题发送给 DeepSeek。问题为 1–500 字符，每次只发一张图片和固定提示，不发历史、知识库、路径、文件名或内部 ID。

返回严格 JSON 回答与引用，证据不足显示非成功状态。成功先持久化再展示；失败可显式重试已固定图片，停止/后台/销毁取消并清零图片和凭据，不自动恢复或重发。

## 2. 页面事项

独立接入需完成系统 Picker、缩略图/移除、Key、明确同意、图片准备、请求进度、取消/停止与失败重试。`pricingState=unverified` 不显示为实际扣费或金额上限。完整接口见 [UI 契约](../docs/integration/原图视觉问答UI交接契约.md)。

## 3. 业务与 Agent 事项

`RuntimeVisionService.session` 管理独立 PERSONAL 单步骤任务，无搜索、工具、记忆查询或自动重试。图片头与 ImageKit 校验静态单帧格式，源文件不超过 20 MB / 20 MP，重编码不超过 8 MB、最长边 2048，并应用 EXIF Orientation。

回答须非空、有界且含有效 `[1]` / citations；insufficient 不生成成功引用。独立加密库 `shuvi_vision_answer_v1.db` 保存执行结果，不保存图片字节、路径或文件名，记录上限 128。每会话最多 10 次模型请求，单请求 60 秒、watchdog 120 秒。

## 4. 平台与费用

使用既有系统选择器、ImageKit、网络与加密库，本功能不新增权限。会话 Key 由现有凭据入口处理；本地 10000 micros 预算门槛没有可信图片单价支撑，不作为供应商费用上限，见 [ADR-017](../docs/architecture/decisions/ADR-017-原图视觉问答费用边界.md)。

## 5. 验收方式

正常图片/回答/引用、图片损坏或超限、EXIF、授权拒绝、取消、持久化失败、模型非法输出和 10 次限制分别验证。证据与复现命令见 [设备清单](../docs/verification/原图视觉问答设备验收清单.md) 和 [真实 API 测试](../docs/verification/原图视觉问答真实API测试.md)。

已有图片处理测试与一次 host 真实 API 结果，各自限定其范围。独立 UI、设备真实 transport、完整 EXIF/超限样本、实际账单、最大字体/读屏和真机仍待验收。
