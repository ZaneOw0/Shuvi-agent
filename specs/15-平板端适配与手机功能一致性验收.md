# 15 平板端适配与手机功能一致性

> 状态：布局已实现，主要手机/平板模拟器对照完成；完整异常、无障碍与真机待验收。
> 范围：同一 HAP 的响应式界面，不包含账号或跨设备同步。

## 1. 用户流程

安装同一应用包后，在手机、平板或改变窗口尺寸时使用相同的助手、日程、知识库与设置。横竖屏、键盘和窄窗切换保留本次运行的草稿、结果与当前页面。

## 2. 页面事项

`ResponsiveLayoutPolicy` 以外层窗口宽度决定布局，不依赖设备型号。

| 项目 | 当前规则 |
|---|---|
| 导航 | 小于 840 vp 使用 Overlay 抽屉；达到 840 vp 使用 Embed 常驻侧栏 |
| 侧栏 | 240–280 vp |
| 内容宽度上限 | 按窗口档位为 640 / 720 / 840 / 960 vp |
| 紧凑操作 | 480 vp 档位压缩操作布局 |
| PDF | 预览层位于导航与内容之上，按当前窗口约束表面 |
| 浮动入口 | 约束在内容区，尺寸变化时重新定位 |

内容页、长文、图片与处理状态使用各自分页；宽屏不放宽数据、授权或任务约束。

## 3. 业务与 Agent 事项

手机、平板复用同一领域模型、服务、处理队列和持久化结构。页面重排不重启模型调用、不重复执行工具、不重置授权与成功进度。跨设备数据、Key 与账号不自动搬运。

## 4. 平台能力

`module.json5` 注册 phone / tablet，UIAbility 自动旋转，窗口尺寸通过现有 ArkUI / window 接入。无新增权限、依赖或云服务。

## 5. 验收方式

四页导航、Overlay/Embed 切换、横竖屏加键盘、草稿和结果保持、PDF 表面、浮动入口、详情分页与设置返回均需对照。异常窗口、权限拒绝、模型失败与取消使用相同业务行为。

命令、HAP 身份、模拟器截图与证据见 [平板端适配与手机对照验收记录](../docs/verification/平板端适配与手机对照验收记录.md)。布局 host 8 项和记录中的设备结果仅覆盖各自版本。

## 6. 当前限制

手机端真实模型/检索、日程写入读回、较大字体、读屏、权限拒绝与真机仍需补验。既有大型知识库在手机模拟器首次打开较慢，需单独处理性能问题。模拟器结果不替代真实平板和 OpenHarmony 验收。
