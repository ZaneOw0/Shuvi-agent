## 编写规则

文件名为 `NN-功能名.md`，功能编号从 01 开始连续且唯一，README 与模板不参与编号。结构与必要字段见 [_模板](_模板.md)。跨模块行为先对齐契约，再实施。

状态采用「待确认 → 已确认待实现 → 已实现待验收 → 已验收 → 已下线」。状态限定具体实现与验收范围；更新为当前描述，验证日期、提交、设备和日志写入验收记录。保留尚未实现目标与真实限制，不把规划写成现有能力。
