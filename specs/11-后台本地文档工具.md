# 11 后台本地文档工具

版本：v0.3，2026-10-27。用户要求模型在正常对话中自主选择文档工具，并将文件保存到系统文件管理器的 Download 目录，不使用固定指令或工具页面。用户已允许所选文档正文外发至 DeepSeek。本次 Download 改动按用户要求不新增或运行测试，功能效果由用户验证；旧版 8/8、201/201 结果不代表本次 Download 行为已验收。

## 用户流程

用户启用现有真实对话后，正常提出生成并保存、读取或修改文档的需求。模型通过标准 `tool_calls` 选择本地创建、读取或更新；宿主验证并通过 Runtime 执行，将真实结果按 `tool_call_id` 返回模型，模型继续回答。更新必须给出读取到的期望版本；冲突时保留已有内容。结果未知时不自动重发。

## 页面事项

不新增页面、菜单、工具按钮或文件选择界面；后台使用 DocumentViewPicker 的 DOWNLOAD 模式取得应用下载目录。更新现有启用说明，明确公开文件、PERSONAL 会话及正文发送到 DeepSeek 的范围。成功写入后，普通聊天答案附真实文件名、版本、保存位置和回执。

## 业务与 Agent 事项

工具遵循现有 Registry、授权、持久化、dispatch 和唯一 AgentRuntimeFacade。写入绑定 operation 与幂等键；同键异参拒绝。保留 main 的必需工具目录检查和取消传播，不绕过搜索账单与恢复约束。

## 平台能力

API 26 使用官方 DOWNLOAD 模式，将 UTF-8 文本/Markdown 保存至 `Download/com.example.shuvi/<fileName>`，文件管理器可见，无需新增权限。正文上限 256 KiB；路径由系统返回的应用下载目录及校验后的文件名生成，模型不能选择任意路径。应用私有不可变版本和加密 RDB 保留提交、版本和操作记录。

公开文件写入也在 Native Runtime 授权派发内完成，工具边界标为 DEVICE_ONLY；只有私有版本提交和下载文件写入、核查均完成才报告成功。先在 Download 内暂存、fsync 和摘要校验，之后才提交私有版本，打开目标文件并通过 FD 复制、fsync、关闭和读回校验；暂存失败不增加内部版本。用户实测此模拟器公开目录 rename 返回 13900012，已经取消该发布方式。检测到同名陌生文件或外部改动时拒绝覆盖。公开文件替换不具备原子性，不提供跨应用事务 CAS；私有提交后遇到取消或写入异常报告不确定，目标可能不完整，但私有历史正文保留。本轮禁用继续写入但允许真实只读核查。模型回答中的 DSML 等标记不能当作工具调用执行，也不能原样冒充执行结果。原有私有文档不会启动时批量外发；用户要求保存旧文档时，由模型读取后调用 update，将该文档保存至 Download。

## 验收方式

契约、失败路径、日志和用户执行命令见 [后台工具集成与测试](../docs/integration/agent/后台本地文档工具.md)。包含正常创建/更新/读取、版本冲突和提交异常、拒绝授权及取消。确定性 fixture Planner 用于验证工具，不将模型自主调用或产品聊天支持当作已验收行为；本工具没有直接模型请求。2026-10-27 19:28 实际模拟器报告为 8/8，证据 `.local/native-documents-device/20261027-192822/`；系统日志导出缺口见集成说明，不以编译替代设备结果。
