# 13 助手多模态消息

> 状态：已实现待验收。单条消息可带文字、1 张图片与语音，统一交给主助手工具循环。

## 1. 用户流程

选择图片或录制语音，按需补充文字；预览、试听与移除草稿后手动发送。模型据图/文字理解问题，并可选择回答、文档工具或日程提议；搜索与知识库授权开启时也可发送图片。

## 2. 页面事项

附件草稿显示在输入框上方，有文字时折叠为一栏；图片可全屏预览，返回键先关闭大图。发送后的消息先展示文字，附件通过箭头展开，语音转写保持隐藏。

图片发送前在应用私有目录保存重编码副本，切换或重启对话后可恢复预览；副本缺失时显示占位。删除对话时删除其图片副本。

## 3. 业务与 Agent 事项

图片只随当前轮次发送，后续轮次和恢复对话不重新携带原图。图片来源、格式、字节及像素边界经既有校验与重编码，去除 EXIF/GPS，不向模型发送路径或原文件名。

语音转写与补充文字合并成同一请求。开搜索时派生关键词可能含从图片或语音得到的信息；知识库与搜索仍受各自授权和工具规则约束。

对话只存受校验的图片副本文件名，不存 URI；模型记忆与 UI 附件恢复分别处理。发送失败保留用户可恢复的草稿与真实保存状态。

## 4. 平台能力与隐私

复用系统图片选择器、现有媒体处理和语音权限，不新增相册权限或供应商。图片仅发给 DeepSeek；本机副本不进入系统备份，见 [对话存储](14-助手对话记忆与历史对话.md)。

## 5. 验收方式

验证普通/搜索/知识库三种授权组合下选图发送、图片加语音、附件折叠/全屏/返回、重启恢复、缺副本占位、删除对话和非法文件名。覆盖拒绝选择或麦克风授权、服务异常、模型失败与取消。

定向入口为 `run-direct-model-tests.cjs` 与 `run-speech-tests.cjs`。真实图片/语音与工具组合、恢复显示和真机矩阵仍需设备取证。

## 6. 当前限制

发送后对话尚未保存即强制结束，可能留下无人引用的图片副本；目前没有图片存储上限或孤儿文件清理入口。独立 [原图视觉问答](08-原图视觉问答.md) 是另一套会话契约，主聊天图片使用本 spec 的流程。
