# 03 联网搜索

> 状态：debug 已实现待验收。手机直连 Tavily，搜索作为主助手工具使用。

## 1. 用户流程

1. 在「我的 → API Key 管理」保存 Tavily Key，启用真实助手。
2. 打开助手页「搜索」，确认本对话自动搜索、外发内容与可能费用。
3. 正常提问，模型按需调用 `web_search`，把公开网页证据用于当前回答。
4. 回答末尾列出引用的 `[Wn]` 网页标题和网址；未直接引用时列出本轮搜索到的网页。
5. 关闭开关、新建/切换/删除当前对话、停止助手或退后台即撤销相应授权，进行中的请求按取消规则收尾。

## 2. 页面事项

- 搜索与知识库可同时授权，开关以文字、边框和背景表示选中；不展示独立搜索面板。
- 授权说明放在开启弹窗中，开启失败用弹窗反馈；进行中可通过「取消回答」取消整轮。
- 来源只附在产生它的回答下。知识库来源卡片和后续网页来源同时保留。
- 开启搜索时可发送图片与语音。图片不直接上传 Tavily，模型生成的关键词可能包含从对话、图片或语音中得到的信息。

## 3. 业务与 Agent 事项

`RuntimeSearchSession` 实现工具端口，`CombinedLoopTools` 与知识库工具共同接入同一助手循环。只开搜索使用普通对话预算；提供或使用知识库工具时采用知识库预算。

| 约束 | 当前值或行为 |
|---|---|
| 每轮调用 | 最多 2 次，每次最多 3 条结果 |
| 超时 | 单次最多 30 秒，并受整轮截止时间限制；剩余不足 8 秒不再发起 |
| 执行 | 同时只允许一个搜索调用，不自动重试 |
| 授权 | Runtime 预览关键词须匹配本次调用；会话授权变化使旧调用失效 |
| 结果 | 运行时校验网页字段；标题去换行，来源按本轮编号绑定 |
| 持久化 | 每次调用为独立 Runtime 任务，派发与结果分别留记录；写入失败不伪造成功 |

搜索执行记录存入应用私有加密库。任务达到 128 条或记录行达到 1.2 MB 后，在打开库时清空整个旧库，再从空库开始；对话中途满库则在下次搜索前重启搜索 Runtime，保留本对话授权。清空失败撤销搜索授权并提示重试，不自动归档或导出。

搜索使用的公开网页摘录可随普通对话记忆保存；涉及知识库的轮次仍遵守知识库临时记忆规则。

## 4. 平台能力与隐私

使用既有网络权限、Tavily HTTPS 适配器、系统安全存储和加密 RDB；当前应用不依赖电脑 MCP 搜索服务或 hdc 转发。[保留的 MCP 服务](../services/search-mcp/README.md) 仅供参考及本机验证。

关键词由模型生成，可能带出上下文信息；当前没有本地关键词脱敏能力。费用记入用户 Tavily 账户，本地预算或用量记录不作为实际扣费报价，供应商账单核对尚未实现。

## 5. 验收方式

| 路径 | 验收重点 |
|---|---|
| 正常 | 授权后工具可见，模型自主搜索、网页引用、知识库混合来源、连续多轮 |
| 异常 | 空结果、非法 URL/字段、超时、满库清空失败、派发与结果写入失败 |
| 授权拒绝 | 未授权、关闭或换对话不派发；提交期间撤销/取消不迟到批准 |
| 模型失败 | 工具失败可理解反馈、无旧来源串轮、整轮取消后无新搜索 |

工具循环与 Tavily 定向用例位于 `entry/src/test/run-direct-model-tests.cjs`、`tavily-direct-tests.cjs`；混合来源回归见 [补丁验证](../docs/verification/发布前补丁验证.md)。完整设备真实搜索、语音/图片上下文、实际账单及真机仍需独立验收。

## 6. 当前限制

仅 debug 开放。来源以文本展示，聊天气泡中的网址暂无专用打开入口。满库会移除本机派发和待核账记录，供应商实际用量仍需到 Tavily 账户核对。
