# 07 Runtime 普通对话接入

> 状态：debug 已实现待验收。主助手采用同一模型会话与自主工具循环。

## 1. 用户流程

1. 配置 DeepSeek Key 并启用真实助手。
2. 发送文字，或带图片、语音及补充文字的消息。
3. 模型按问题选择直接回答、澄清、文档工具或日程提议；搜索和知识库工具在用户授权后可用。
4. 日程提议在用户确认后写入系统；搜索和知识库返回各自来源。
5. 用户可取消回答、切换/新建对话或停止真实助手。历史普通对话可恢复，工具授权需重新开启。

## 2. 页面事项

- 助手输入、消息、附件、取消与来源使用统一组件。知识库和搜索可同时开启，不显示重复的搜索面板。
- Key 管理、启用说明和工具外发范围可查；加载、工具执行、错误、取消与成功分别投影。
- 回复先按真实来源绑定生成卡片；纯文字、日程结果、文档回执和来源保持各自语义。
- 导航、宽屏侧栏、浮动入口和键盘布局见 [多设备契约](15-平板端适配与手机功能一致性验收.md)。

## 3. 业务与 Agent 事项

`RuntimeAssistantCoordinator` 组合知识库与搜索工具端口；`RuntimeChatService.session.send` 是主对话发送入口，`DeepSeekToolTransport` 驱动模型 tool_calls。业务操作经生产 Runtime 执行。

普通助手预算、摘要与恢复见 [对话记忆](14-助手对话记忆与历史对话.md)。知识库工具启用或使用后采用其独立的请求/证据上限与临时记忆规则。搜索授权不单独触发知识库模式。

会话纪元、截止时间、取消和授权变化绑定本轮；旧工具结果和迟到响应不得进入新对话。失败保留真实阶段，不自动切换演示数据。

覆盖普通回答、澄清、工具连续调用、知识库/搜索组合、取消、恢复、错误提示及跨页会话保持；分别验证权限拒绝、服务异常、模型失败与结果未知。

主机回归入口为 `entry/src/test/run-direct-model-tests.cjs`；语音、日历、布局和知识库另有定向用例。[集成回归](../docs/verification/PR26-main合入与RAG三链路回归.md) 与 [补丁验证](../docs/verification/发布前补丁验证.md) 保留具体命令与版本。真实模型意图质量、异常路径、实际账单和真机矩阵仍待完整取证。
