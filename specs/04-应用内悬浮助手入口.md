# 04 应用内悬浮助手入口

> 状态：主要模拟器交互已有人工验收；完整窗口与无障碍矩阵待验收。

## 1. 用户流程

用户离开助手页后，通过应用内容区内的浮动入口返回当前对话。入口可拖动，松手后向左右边缘吸附；「我的」可关闭本次运行的入口。

## 2. 页面事项

入口限制在内容区域，不覆盖系统桌面或其他应用。拖动与点击区分；导航、窗口大小和键盘变化后重新约束位置，返回助手保留当前消息与草稿。

开关和位置仅本次运行有效，重启恢复开启并回到初始位置。手机和平板共享布局策略，见 [多设备适配](15-平板端适配与手机功能一致性验收.md)。

## 3. 业务与 Agent 事项

入口只切换应用页面，不启动模型、不创建新对话、不变更工具授权，也不恢复后台已停止的请求。

## 4. 平台能力

使用现有 ArkUI 布局与手势，无悬浮窗权限、跨应用窗口或额外存储。

## 5. 验收方式

覆盖返回当前对话、拖动吸边、边界约束、关闭与重启、横竖屏和键盘变化；异常窗口尺寸下仍可到达入口，点击不触发外发或系统写入。

定位策略的定向 host 用例与 [多设备验收记录](../docs/verification/平板端适配与手机对照验收记录.md) 提供相应范围证据。读屏、其他窗口模式和真机待验收。
