## 1. 用户流程

1. 用户在前端选择一张 JPEG / PNG / WebP 图片。
2. 前端把系统 Picker 返回的 URI 与显示名交给 `RuntimeVisionService.session.attachImage(uri, name)`；后端只读取一次，重新编码为去除容器元数据的图片，不把原图路径、文件名或 EXIF 写入模型提示词。
3. 用户输入本次问题（1–500 字符），启用会话时已明确同意“原图重新编码后发送给 DeepSeek”。
4. 发送后只发起一个 PERSONAL 模型任务：图片 + 本次问题 + 固定系统提示。
5. 模型必须返回严格 JSON：`{"answer":"...","citations":[1]}`；回答非空、有界、至少一个 `[1]`，否则不显示为成功。
6. 成功结果先写入独立加密执行库 `shuvi_vision_answer_v1.db` 再显示；失败/取消保留图片与问题，可显式重试回答；重试重新发送同一张已固定图片，不重新读取或重新编码。
7. 停止/退后台/页面销毁时取消当前请求、关闭凭据、清空图片字节；不自动恢复或重发。

## 2. 页面事项（前端负责）

- 系统图片 Picker：仅 JPG/JPEG/PNG/WebP；不新增相册/文件读取权限，继续使用系统选择器的 URI 授权。相机、多图、文件输入不在本 spec 范围。
- 缩略图、移除图片、禁用态、读取/校验进度、错误提示。
- Key 密码输入、关闭自动填充/预览、组件消失时清空输入字符串；Key 只以 `Uint8Array` 交给后端。
- 明确同意：原图会重新编码后发送给 DeepSeek；只发送本次问题与一张图片；不发送文件名、路径、历史消息、知识库或内部 ID；实际处理、留存和费用以供应商规则为准。
- 展示 `stage`、`message`、`answer`、`imageReady/imageName/imageMime/imageWidth/imageHeight`、`requestCount/maxRequests/pricingState`；不展示内部路径、哈希或数据库 ID。`pricingState=unverified` 时不得显示为实际扣费或金额上限。
- 忙碌时“取消当前”，空闲时“停止会话”；`answerFailed` 显示“重试回答”；`insufficient` 显示为非成功结论，不伪造引用。
- 页面离开、切标签、Ability 退后台时停止；返回前台不自动恢复。

## 3. 业务与 Agent 事项

- 独立 `RuntimeVisionService.session` / `RuntimeVisionSession`；普通 PUBLIC 聊天仍不接受图片，未被放宽。
- `VisionAnswerPlanner` 只生成一个 LLM 步骤 `vision-answer`；无工具、MCP、搜索、记忆查询、自动重试或 replan。
- `VisionAnswerModelAdapter` 使用应用层 `ArkTsVisionChatTransport`，不修改 `modules/harmony_agent` 的 `ModelMessage` / `ProviderContracts`。
- 传输使用当前会话的 `SessionModelCredentials`，模型 ID 取启动配置；不读取知识库持久视觉凭据，不把聊天 Key 写入 AssetStore/日志/数据库。
- 图片必须通过 `imageInspectHeader` 与 ImageKit 双重校验：仅静态、单帧、JPEG/PNG/WebP；源文件 ≤20MB、≤20MP；重新编码后 ≤8MB、最长边 ≤2048；不满足则拒绝发送。
- 重新编码通过 ImageKit 解码 + 打包完成，去除容器元数据；已读取 EXIF `Orientation` 并应用 1–8（旋转/镜像），设备测试覆盖 Orientation=6；其他方向值仍需更多设备样本。
- 模型输出复用知识库回答的严格 JSON/引用/`insufficient` 校验；`insufficient` 文案为“资料中没有足够依据”，不生成引用。
- 独立执行库 `shuvi_vision_answer_v1.db`，schema `shuvi-vision-answer-1.0`，最多 128 条记录；不保存图片字节、文件名、路径或问题明文到该库（任务 checkpoint 由既有 Runtime 结构保存）。无自动恢复、对账或重发。
- 每次会话最多 10 次模型请求；第 11 次在 `RuntimeVisionSession` 层直接返回 `false`，不提交任务；单次超时 60 秒；120 秒 watchdog；达到上限后需停止并重新启用。`requestCount` 在重新启用时重置。
- 显式同意后仍只发送：一张重新编码图片、本次问题、系统提示；不发送知识库片段、历史、文档、文件名、路径、`evidenceId`、`generation` 等内部信息。
- `maxMonetaryCostMicros` 仅为 Agent 预算门槛（10000 micros）；没有图片计费单价，不声称覆盖实际图片费用，实际扣费以 DeepSeek 账单为准。
- 持久化成功后才显示成功；`recordOutcome` 拒写通过 `onOutcomeRejected` 立即结束并保留图片，可重试。

## 4. 平台能力

- 图片选择：系统 `DocumentViewPicker`（现有 `@kit.CoreFileKit`），无新增权限。
- 图片解码/编码：`@kit.ImageKit`（`ImageSource` / `ImagePacker`），使用现有 SDK API，不新增依赖。
- 网络：DeepSeek `https://api.deepseek.com/chat/completions`，`response_format: json_object`、`thinking: disabled`、`stream: false`；请求体只包含系统提示、问题文本和 `data:<mime>;base64,...` 图片。
- 加密执行库：独立 `shuvi_vision_answer_v1.db`；不写入聊天、知识库工具或知识库回答库。
- 当前 `module.json5` 仅 `INTERNET`；本功能不新增权限。
